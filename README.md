# cutePet · 宠物生活服务平台

> 面向宠物管理、宠物资讯、宠物探索、宠物用品四大领域的一体化项目。
> 四端：用户端 Web（18580）· 管理端（18581）· 官网（18582）· 移动 H5（18583）。
>
> **当前状态：M0–M12 全部 13 个模块「开发完成」（2026-09-22，R17）——
> 进入待负责人本地测试与修复阶段**（本机为设计机，仅文档+代码+进程内纯逻辑测试；
> 编译/启动/E2E/真机等运行验证归本地测试阶段，证据分层见
> [L与E证据隔离说明](docs/06-测试用例/L与E证据隔离说明.md)）。

## 项目定位

| 模块 | 说明 |
|------|------|
| 🐾 宠物管理 | 档案（4 步建档）、健康记录 7 类、体重曲线（10%确认/5%高亮）、提醒（固定间隔/周期日双基础）、健康摘要（仅所有者） |
| 📰 宠物资讯 | 7 频道先审后发、评论机审（先发后审+仅自见态）、创作中心（文章/评测/清单，3 次退修暂停 7 天不计违规） |
| 🗺️ 宠物探索 | 5 城 200 POI、评价防刷（1天1条/全5短文复审）、遛宠路线、活动报名（8 拒因+告知同意）、领养信息（无报名/交易按钮） |
| 🛍️ 宠物用品 | 纯内容导购（一期无交易）：商品库（**兽药/处方三通道禁入**）、清单与评测绑定、治理清除引用降级 |

## 技术与结构

- **栈**：Turborepo 2 · Vue3+Vite6+TS5.4（四端）· Java 25 + Spring Boot 4.1 多模块（9 服务）· MySQL owner-schemas + Flyway · 端口 18470–18488/18580–18583
- **契约优先**：`packages/contracts`（**153 路由 / 32 权限点 / 6 预置角色**）→ `scripts/gate.mjs` 七检 → `packages/api-client` 生成产物
- **9 服务**：gateway · iam · pet · content · explore · catalog · admin-ops · notification · audit + common-core/common-web
- **测试**（零环境，本机可跑）：
  ```
  node scripts/run-logic-tests.mjs          # TS+Java 纯逻辑测试（32+ 文件）
  node scripts/gate.mjs                     # 七检：测试/契约/端口/服务结构
  node scripts/quality/test-coverage-report.mjs  # T11.1 覆盖核对（8 规则域）
  ```
