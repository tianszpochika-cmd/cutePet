# cutePet · 宠物生活服务平台

> 面向宠物管理、宠物资讯、宠物探索、宠物用品四大领域的一体化项目。
> 支持多端：用户端 Web、官网、管理端、移动端。

## 项目定位（草案）

| 模块 | 说明 |
|------|------|
| 🐾 宠物管理 | 宠物档案、健康记录、免疫驱虫、体重曲线、日程提醒 |
| 📰 宠物资讯 | 科普文章、养宠知识、行业动态、内容推荐 |
| 🗺️ 宠物探索 | 附近宠物店/医院/公园、遛宠路线、宠物友好场所 |
| 🛍️ 宠物用品 | 商品展示、分类导购、（预留）交易能力 |

## 多端矩阵

- **用户端 Web**：面向养宠用户的核心功能体验
- **官网**：品牌展示、产品介绍、SEO 流量入口
- **管理端**：内容运营、商品管理、用户与数据运营
- **移动端**：随时随地的轻量体验（形态待定，见需求文档）

## 当前阶段

**阶段一：需求与设计（当前）** → 阶段二：技术选型 → 阶段三：开发实施 → 阶段四：测试上线

⚠️ 本阶段**不做技术架构选型**，一切以 `docs/` 下的需求文档和设计文档为准。
