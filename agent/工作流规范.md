# Agent 工作流规范

> 配合 `AGENTS.md` 使用，定义需求/设计阶段的典型任务流程。

## 任务类型与流程

### A. 编写/修订需求文档
1. 读 PRD 总纲 + 相关模块旧文档
2. 补齐用户故事、业务规则、边界异常、多端差异
3. 将无法决策的点写入「待定」与评审记录
4. 更新状态头

### B. 编写/修订设计文档
1. 以需求文档为唯一输入（需求未定处不得自行拍板）
2. 产出后回检：设计是否覆盖全部 P0 需求
3. 需求缺口 → 反馈回需求文档，标注来源

### C. 评审支持
1. 汇总各文档「待定」项
2. 输出待决清单供人类决策
3. 决策回填后更新相关文档

## 禁止事项

- 禁止在需求/设计文档中引入技术选型。
- 禁止删除他人的定稿内容（走 archive 流程）。
- 禁止虚构已完成的调研数据（调研结论须注明来源或标注「假设」）。
