# 官网设计 · 页面架构（Site Map）

> 状态：评审中（闭环修订完成） · 版本：v1.1 · 更新日期：2026-09-22
>
> 目标：**页面多、介绍细**——27 个路由的完整官网架构；官网定位 = 品牌展示 + SEO 获客 + 各端入口引导（只读，不做写操作，见信息架构 §6）。

## 1. 全局导航（所有页共享）

**顶部导航（吸顶）**
```
[Logo]  产品 ▾   场景 ▾   资讯   活动   关于 ▾   帮助        [🤖 打开 Web 端] [📱 手机打开]
```
- 「产品 ▾」：总览 + 4 产品页（带图标与一句话）
- 「场景 ▾」：总览 + 3 场景页
- 「关于 ▾」：关于我们 / 加入我们 / 联系我们
- 滚动 >64px → 吸顶栏渐显毛玻璃背景 + 阴影；移动端收进汉堡菜单（全屏抽屉）

**页脚（全站）**
```
产品矩阵(4) | 场景(3) | 资源(资讯/活动/帮助) | 关于(关于/招聘/联系)
用户条款(用户协议/隐私政策/社区规范/儿童规则/投诉举报与版权通道)
© 20XX cutePet · ICP备案号XXX(链工信部) · 公安备案号XXX · 官方邮箱/公众号
```

## 4. SEO 结构

- 每页独立 title/description/OG（分享卡片）；产品页与场景页互链形成内链网。
- `/journal/:slug` 与用户端文章同源，canonical 指向用户端，官网页做展示层导流。
- 法律五页与帮助中心承担客服 SEO 长尾（"XX 怎么注销"等）。
- `sitemap.xml` + `robots.txt` 随上线清单（见冷启动运营计划 §3）。

## 当前入口与生命周期

官网以“开始使用/手机打开”提供可用入口；不存在的安装包不展示下载按钮。公开内容与用户端同源按当前已发布版本展示，下架后同步不可用。健康摘要不挂实时私有档案链接。活动CTA回用户端对应详情，登录后仍须确认报名。
