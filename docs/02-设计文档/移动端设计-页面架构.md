# 移动端设计 · 页面架构（Screen Map）

> 状态：评审中（闭环修订完成） · 版本：v1.1 · 更新日期：2026-09-22
>
> 结构 = **4-Tab 底部导航 + 认证栈 + 全局浮层 + 独立页**，覆盖从登录到全部功能的 **基础 #1–57 与补充 X01–X16 的逻辑页面/状态**。
> 依据：`信息架构.md` §3（4-Tab 决议）、`需求-多端需求矩阵.md`（移动端全量）、功能设计各子文档。

## 1. 全局骨架

```
App
├── L0 启动与授权层（首次）
│   ├── 启动页 Splash（品牌 + 加载）
│   ├── 首次启动隐私弹窗（同意后使用相关服务；不同意可进入受限游客浏览）
│   └── 权限申请（定位/相机/通知 — 用到时才申请，附用途说明）
├── L1 认证栈（未登录可浏览，写操作闸门进入）
│   ├── 登录页 → 验证码页 →（新用户）年龄询问 → 监护人同意流程(≥14 跳过)
│   └── 养宠标签引导（可跳过）
├── L2 主体（4 Tab + 各自导航栈）
│   ├── 🏠 首页 Tab
│   ├── 📰 资讯 Tab
│   ├── 🗺️ 探索 Tab
│   └── 👤 我的 Tab
├── L3 全局浮层
│   ├── 登录闸门弹层 / 分享面板(bottom sheet) / 举报面板(bottom sheet)
│   ├── 筛选面板、日期与单位选择器、图片选择（相机/相册）
│   ├── 确认对话框（二次确认）/ Toast / 骨架屏 / 空态
└── L4 独立页
    ├── 帮助与客服 / 申诉 / 规则页(4+1) / 封禁提示页 / 通用错误页
```

## 3. 导航栈与手势规则

- **Tab 切换**：保留各自导航栈与滚动位置；双击同一 Tab → 回到该栈根并滚回顶部。
- **推入/返回**：右上角返回 + **左缘侧滑返回**（iOS 全局 / Android 物理返回优先）；详情页返回回原位（列表滚动位置不丢）。
- **Bottom Sheet**：记录表单、筛选、分享、举报、选择器——下拉关闭 + 背板点击关闭（有输入内容时拦截确认）。
- **深链路由表**（通知/分享统一回跳）：

| 来源 | 落点 |
|------|------|
| 提醒推送 | 宠物详情 → 提醒 Tab，定位到该提醒 |
| 审核结果 | 投稿状态详情 |
| 家庭邀请 | 加入家庭页 |
| 分享卡片 | 公开文章/清单/路线/活动等落公开详情；摘要静态图仅附产品入口，不开放私有档案 |
| 登录闸门回跳 | 登录后返回原页面原操作位（L1/L3 不断链） |

## 4. 权限申请时机（合规：用到才申请 + 用途说明）

| 权限 | 时机 | 文案要点 |
|------|------|----------|
| 通知 | 首次创建提醒 / 注册完成后 | 「用于接种、驱虫等重要提醒」 |
| 定位 | 进入探索 Tab | 「展示你附近的宠物友好场所；拒绝可手动选城市」 |
| 相机/相册 | 首次记录照片/评价/头像 | 「用于记录宠物照片与评价配图」 |

拒绝核心权限不阻塞主功能（定位拒绝→城市兜底）。

## 5. 生命周期导航补充

[闭环页面与状态](功能设计-闭环页面与状态.md) X01–X16全部纳入一期：我的→活动中心/待同步，宠物列表→归档回收站，宠物→授权/转移/计划历史，家庭→管理员转交，创作→类型选择/清单/修改版本，登录与帮助→监护人/受限账号。页面复用不得省略对应入口与状态。
