# 移动端设计 · 动效与交互规范

> 状态：评审中 · 版本：v1.0 · 更新日期：2026-09-22
>
> 原则：**跟手、轻盈、有生命感**——动画服务于「我在哪、发生了什么」，全部手势可打断（动画中途反手立即响应）。
> 与官网动效同源令牌，本文定义移动端（触屏/手势）专属。

## 1. 动效令牌

**缓动**

| 令牌 | 曲线 | 用途 |
|------|------|------|
| `--e-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 推入、抬升、入场（主用） |
| `--e-in` | `cubic-bezier(0.55, 0, 1, 0.45)` | 返回、退出 |
| `--e-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 状态切换、Tab |
| `--e-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 点赞/收藏/完成等点缀（小元素专用） |
| `--e-gesture` | `linear`（跟手阶段） | 手势驱动位移，松手后交给物理动画 |

**时长**：即时 100ms（按压反馈）· 快 200ms（开关/Chip）· 标准 300ms（推入/弹层）· 慢 450ms（大面板/入场）· 级联 stagger 50ms（同屏 ≤6 项）。

**物理跟手**：屏缘返回、下拉刷新、Sheet 拖拽均为**位移=手指位移**；释放后按 300px/s 速度阈值决定完成/回弹（`--e-out` / `--e-spring`）。

## 2. 导航与页面动效

| 场景 | 规格 |
|------|------|
| 推入（进入详情） | 新页从右侧 100% 滑入 300ms `--e-out`，旧页左移 25% 变暗（视差 0.3）；**左缘右滑可跟手返回**，松手过 40% 或速度阈值完成返回 |
| 返回 | 逆过程 280ms `--e-in`；返回后列表**保持滚动位置与选中态** |
| Tab 切换 | **无位移**：内容交叉淡化 150ms + 图标上弹微跳（`--e-spring` 200ms，scale 1→1.15→1）；各自栈与滚动位保留 |
| 二级 Tab（分段/子 Tab） | 白滑块 `translateX+width` 250ms `--e-standard`，内容随滑入方向 8px 交叉滑动 |
| Bottom Sheet 开 | 背板淡入 200ms + 面板上滑 300ms `--e-out`；拖拽跟手，关闭 250ms `--e-in` + 背板同步淡出 |
| Dialog | 背板 150ms + 卡片 `scale(0.94)→1` 250ms `--e-spring`（无位移，居中稳定感） |
| Toast | 顶部下移入场 200ms `--e-out` + 淡出 150ms |
| 页面加载 | 顶部 2px 进度线（不确定时 60% 循环滑动 1s）；到达后内容渐显 200ms |

## 3. 手势交互（触屏核心）

- **屏缘返回**：见上；全二级页开启，跟手中旧页同步视差。
- **下拉刷新**：列表/Tab 根页可用——指示器随下拉旋转拉伸，达阈值 60px 触发刷新（转圈 800ms 循环），松手回弹 300ms；刷新成功顶部轻震（Haptics 轻）+ 时间戳更新。
- **上拉加载**：触底自动加载（骨架 3 行）；已无更多 → 底部「— 到底啦 —」一次浮入。
- **左滑操作**：列表项左滑露出操作（取消收藏/删除/归档），露出宽 72，滑动跟手 + 松手吸附；需二次确认的操作（删除）滑开后仍弹确认。
- **横滑容器**：卡片轮播/分类 chip 支持惯性滚动，吸附居中（分页点/首卡对齐）。
- **长按**：收藏长按多选（振动反馈 + 进入选择态）；图片长按存图菜单。
- **曲线双指缩放**：区间随捏合平滑缩放（禁用页面级缩放冲突）。

## 4. 列表与内容动效

- **骨架→内容**：交叉淡化 200ms；图片 `opacity 0→1` 300ms（decode 后触发），首屏 LCP 图直出不等动画。
- **列表入场**：首屏可见项 `translateY(12px)` 淡入 300ms `--e-out` stagger 50ms（仅首屏，滚动加载项不重播）。
- **卡片按压**：`scale(0.98)` 100ms 按下回弹（触感反馈）。
- **收藏心形**：点击 `scale 1→1.3→1` `--e-spring` 300ms + 填充色切入；取消 = 淡出填充 150ms。
- **点赞**：拇指图标同参数弹跳；计数数字翻牌（旧数上移淡出、新数下方进入 180ms）。
- **关注按钮**：文字变「已关注」时底色 200ms 渐变 + 轻微缩放确认。

## 5. 核心功能动效（产品生命链）

### 5.1 记录成功（L2 关键愉悦点）
- 保存 → Sheet 下收 250ms → **对勾形变**：按钮位短暂 morph（或 Toast 内 ✓ 描边绘制 400ms）→ 轻 Haptic。
- 数据联动：时间线新条目从上方 8px 滑入 + 高亮底色渐隐（1.2s）；**曲线新点落入**（从上方 `translateY(-16px)` 落位 `--e-spring`）+ 曲线段重绘。

### 5.2 体重曲线绘制
- 首次进入：路径 `stroke-dashoffset` 从 0→全长 800ms `--e-out`，数据点依次 scale-in（stagger 60ms）；趋势徽章最后弹入。
- 数据点选中：点放大 1.2 + 竖向参考线生长 150ms。

### 5.3 提醒完成
- 卡片左滑/点 ✓ → 圆圈勾选描边绘制 300ms → 卡片折叠高度收起 250ms 挪入「已完成」分组 → 轻 Haptic。
- 首页提醒条消除：向左滑出 250ms + 下一条上补位 200ms。

### 5.4 建档向导
- 步进：内容左右滑 300ms（跟手）+ 进度条段落填充 250ms。
- 完成页：撒花粒子一次爆发（≤40 粒，600ms，只播一次）+ 主宠物头像 `scale(0.9)→1` `--e-spring`；「设第一个提醒」卡延迟 300ms 浮入。

### 5.5 探索地图
- POI 钉落下：`translateY(-24px)→0` 落地 + 底部阴影脉冲 350ms，多个 stagger 70ms；每 4s 随机一枚轻跳一次（全屏循环钉 ≤1）。
- 选中钉：放大 1.15 + 白描边 200ms，底部卡滑入替换 300ms（交叉滑动 12px）。
- 列表⇄地图联动：选中卡滚动居中 + 钉同步高亮（双向，150ms）。
- 聚合点点开：数字点缩放消散 + 单钉散开 `--e-spring` 350ms。

### 5.6 写评价 / 发布
- 星级点选：星 `scale 1→1.15→1` + 逐颗延迟 40ms 级联点亮。
- 发布成功：✓ 徽章绘制 + Toast「感谢贡献」；评价卡上屏滑入。

### 5.7 记录类 Haptics（触感）
| 场景 | 反馈 |
|------|------|
| 记录保存 / 提醒完成 / 评价提交 | 轻震（impact light） |
| 里程碑（建档完成、家庭创建） | 中震（impact medium） |
| 危险操作确认（删除/封禁提示） | 无（仅视觉，避免误导成功感） |
> Haptics 不可用平台静默降级。

### 5.8 分享与深链落地
- 分享面板升起 300ms；生成分享图：缩略图从内容区 `scale(0.96)` 浮出 350ms。
- 深链落地：目标页正常推入 + **关键区块 200ms 高亮底色渐隐**（提示「从这里进来的」）。

## 6. 降级与低端机策略（强制）

```css
@media (prefers-reduced-motion: reduce) {
  /* 位移/缩放/视差/循环动画/粒子 → 全部关闭，仅保留 ≤100ms 的 opacity */
  /* 页面切换改为纯淡入淡出 100ms；撒花/粒子不播 */
}
```
- Haptics 独立开关（设置-通知设置内），默认开、可关。
- **低端机判定降级**（实现层）：帧率连续 <45fps → 自动关闭视差、循环漂浮、粒子与地图钉动画（保留功能性过渡）。
- 循环动画配额：**同屏 ≤1 个**（官网为 3，移动端更严）。
- 无 JS/SSR 场景内容默认可见；动画类由运行时挂载。

## 7. 性能预算与验收

- 全程 ≥55fps（中端 Android 实测：推入、Sheet、地图钉三场景重点测）。
- 动画只用 transform/opacity；列表滚动不绑定 JS 逐帧监听（IntersectionObserver/原生滚动）。
- 首屏可交互 ≤2s（中端机 4G）；LCP ≤2.5s；单页面 JS ≤120KB gzip。
- **验收清单**：① 屏缘返回跟手无卡顿 ② 每个 Sheet 拖拽可中断 ③ reduced-motion 全过 ④ Haptics 路径全过 ⑤ 375/414/折叠屏三尺寸走查无溢出 ⑥ 低端机自动降级生效。
