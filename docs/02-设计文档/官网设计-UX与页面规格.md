# 官网设计 · UX 与页面规格（逐页）

> 状态：评审中 · 版本：v1.0 · 更新日期：2026-09-22
>
> 每页给出：**页面目标 → 区块栈（从上到下）→ 内容细项 → 交互 → 响应式 → 状态**。
> 通用规则：① 所有写表单本地校验 + 提交成功/失败态；② 图片懒加载 blur-up；③ 每页进入触发 §动效规范 的章节入场；④ 游客可读一切，CTA 一律带 UTM 参数进入用户端。

## 0. 全站通用组件行为

- **顶部导航**：滚动 >64px 吸顶渐显；下拉菜单 hover/click 展开（桌面）、全屏抽屉（移动）；当前栏目高亮。
- **双 CTA**：`打开 Web 端`（主按钮）+ `下载 App`（次按钮），出现在导航、Hero、页尾三处（粘性转化）。
- **页尾 CTA 章节**（所有栏目页共用）：大标题 + 双按钮 + 二维码卡（hover 放大 + 扫码提示）。
- **返回**：内容/帮助/法律详情页顶部显示面包屑。

## 1. `/` 首页（旗舰页）

**目标**：10 秒内讲清「一站式宠物生活服务平台」，完成双转化（打开 Web / 下载）。

**区块栈**
1. **Hero**（首屏 100vh 内）：主标题「让每一天，都更懂你的宠物」+ 副标（管理·资讯·探索·用品 四词轮播）+ 双 CTA + 右侧主视觉（宠物 IP 插画 + 漂浮元素：爪印/骨头/定位针）
2. **信任条**：滚动数字（注册养宠家庭 / 收录场所 / 精选文章——运营填数，count-up 动效）
3. **四大模块矩阵**：2×2 大卡（各带模块色、图标、3 个要点、探索链接）→ 对应 4 产品页
4. **场景化 Story（横向叙事）**：3 步滑块「早上设提醒 → 白天看资讯 → 傍晚带出门」截图轮播 + 步骤指示器
5. **家庭共享特色块**：双人插画 + 权限两档说明 + 链接 `/features/family`
6. **精选资讯流**：6 张文章卡（分类 chip、封面、标题、作者）+ 「查看更多」→ `/journal`
7. **本地活动条**：横向卡片列表（城市切换下拉）→ `/events`
8. **用户口碑墙**：3–6 条短评卡片（头像+昵称+一句话+宠物标签），轮播
9. **媒体报道/合作伙伴 Logo 墙**（可空态隐藏）
10. **页尾 CTA** + 页脚

**交互**：Hero 元素视差（鼠标移动微位移 ≤8px）；矩阵卡 hover 抬升+图标动；数字进视口 count-up；Story 滑块支持拖拽与键盘。

**响应式**：Hero 单列（插画下移）→ 矩阵 1 列 → Story 竖排步骤；口碑墙变纵向轮播。

**状态**：数字未配置 → 隐藏信任条；口碑/报道空 → 整块隐藏。

## 2. `/products` 产品总览

1. 页头（面包屑首页 > 产品；标题「一个平台，四件小事」+ 导语）
2. **产品矩阵**：4 张大横卡（左文右图，模块色渐变角标；每卡：一句话定位 + 4 功能点 + 双按钮[了解详情/直接体验]）
3. **能力共性带**：账号打通/多端同步/隐私保护/免费使用 4 个 icon 条目
4. 数字信任条（复用）
5. 页尾 CTA + 页脚

**交互**：卡片 hover 内部插画微动 + 模块色描边流光；点击整卡可进（无障碍：内链可聚焦）。

## 3–6. 四个产品详情页（统一模板，内容各异）

**模板区块栈**
1. 页头（面包屑 + 模块色 eyebrow 标签 + H1 + 导语 + 双 CTA + 右侧界面 Mockup 展示台）
2. **核心能力区**：6 个功能点（2×3 卡：图标 + 标题 + 2 行说明 + 截图小图）
3. **深度分节 ×3**（左右交替图文，每节一个 H2 + 段落 + 功能截图 + 要点列表）——"介绍很细"的核心
4. **流程步进区**：4 步编号流程（横向时间轴，滚动依次点亮）
5. **FAQ 折叠区**（该模块 4–6 问，SEO 长尾）
6. **关联推荐**：→ 另外 3 个产品页 + 家庭共享页
7. 页尾 CTA + 页脚

**各页内容差异**

| 页 | H1 | 深度分节（3 节主题） | 特色区 |
|----|----|----------------------|--------|
| 管理 | 「宠物的健康档案，从此一张表讲清」 | ① 体重曲线与趋势预警 ② 六类健康记录+疫苗自动排期 ③ 周期提醒（推送演示） | 提醒通知的手机 Mock 动画演示 |
| 资讯 | 「可信的养宠知识，刷着刷着就会了」 | ① 七频道分类体系 ② 作者与投稿生态 ③ 收藏/关注/个人知识库 | 文章卡片翻牌展示 |
| 探索 | 「带宠出门，先看这一份清单」 | ① 地图找附近 ② 宠物友好属性筛选 ③ 评价纠错与遛宠路线 | 地图钉逐个落下动画 |
| 用品 | 「不卖货，只帮你选对」 | ① 商品库与参数要点 ② 评测怎么写 ③ 好物清单订阅 | 商品卡对比陈列 |

**交互**：Mockup 展示台 30° 倾斜、hover 回正；分节图文交错淡入；FAQ 手风琴平滑展开（高度过渡）；步进区滚动点亮。

## 7. `/features/family` 家庭共享（特色长页）

1. Hero：一家人+宠物插画；H1「养宠，是一家人的事」
2. **权限两档可视化解析**：交互式对比表（hover 高亮行）——可管理 vs 只读
3. 三步邀请流程（生成邀请码 → 家人加入 → 提醒同步）带动画演示
4. **一人一家庭规则说明卡**（规则透明化）
5. 隐私说明：档案可见范围示意（锁形图标 + 范围图）
6. FAQ ×3（能否多家庭/成员能看到什么/移除后数据）
7. 页尾 CTA

## 8–11. 场景方案页（模板：`/solutions*`）

1. 场景 Hero（真实感文案 + 插画：如「第一次养猫的你」）
2. **痛点三连**（卡片翻转：痛点 → 平台如何解决）
3. **解决方案组合**：按场景挑选的产品能力组合（跨模块能力在此聚合介绍，带跳转）
4. 时间轴叙事：一天/一周的使用剧本（垂直时间轴 + 滚动点亮）
5. 相关文章 3 篇 → `/journal`
6. 页尾 CTA

## 12. `/journal` 资讯列表

1. 窄页头（H1 + 搜索框）
2. **频道 Tab**（7 频道 + 推荐，Tab 滑块指示器，URL 同步 `?ch=`）
3. 置顶大卡 1 + 网格列表（12/页，卡片=封面/分类 chip/标题/摘要/作者/时间）
4. 分页（数字页码 + 上下页）
5. 侧栏（桌面）：热门榜 Top5（序号徽章）、标签云
6. 页尾 CTA

**状态**：无结果 → 空态插画 + 推荐频道；加载 → 骨架屏 shimmer。

## 13. `/journal/:slug` 文章详情

1. 面包屑（首页 > 频道 > 标题）
2. 标题 H1 + 作者卡（头像/名/发布日期/阅读时长）+ 分享按钮组（复制链接/微信二维码弹层/微博）
3. 正文排版区（最大宽 720px；h2/h3、引用、图片带说明、列表；**疾病健康频道文末固定免责声明**）
4. 文内商品卡（若有，标注「相关推荐」+ 跳用户端）
5. 互动条：点赞/收藏（引导登录弹层 → 跳用户端回跳）+ **举报入口（合规）**
6. 相关文章 ×3 → 页尾 CTA
7. **阅读进度条**（顶部细线，随滚动填充）

## 14–15. `/events*` 活动列表与详情

- **列表**：城市选择 + 类型筛选（集市/领养日/课程）+ 卡片流（时间徽章大字、地点、报名状态）。
- **详情**：头图 + 标题时间地点卡 + 图文详情 + **报名按钮 → 跳用户端报名表单**（页内注明「报名在 App/Web 内完成，含信息告知」合规提示）+ 分享。
- 空态：该城市无活动 → 推荐热门城市。

## 16. `/download` 下载与入口（转化页）

1. Hero：H1「随时随地，记录它的每一天」
2. **双端卡**：Web 端（按钮直达，附 URL 复制）/ 移动端（**二维码 + iOS/Android 按钮**，形态未定时显示"即将上线"占位 + 邮件订阅提醒表单）
3. 功能预览轮播（3 屏产品截图，自动轮播 + 手动）
4. 版本更新日志（Changelog 简表，可空态）
5. 常见问题 ×3（哪些平台/收费吗——免费/数据安全）
6. 页脚

**交互**：二维码卡 hover 放大 + 边框扫描线动画；复制 URL → Toast「已复制」。

## 17–19. 品牌三页

- **`/about` 关于我们**：品牌故事（时间轴：起源→理念→现在）→ 价值观三卡（科学/温暖/克制）→ 团队/顾问 Logo 墙（可空）→ 里程碑数字 → 加入我们/联系 CTA。
- **`/careers` 加入我们**：文化介绍 + **职位列表**（手风琴展开：职责/要求/投递邮箱）+ 简历投递说明；无职位 → 空态与联系邮箱。
- **`/contact` 联系我们**：联系表单（姓名/邮箱/类型下拉[商务·媒体·反馈·其他]/留言，本地校验 + 成功态）+ 官方邮箱/公众号二维码 + 办公地址（**不展示精确地图可留占位**）。

## 20–21. 帮助中心

- **`/help`**：搜索框（回车跳 `/search`）+ 分类网格卡（账号与安全/宠物档案/内容与投稿/探索与活动/隐私与合规，各带文章数）+ 高频问题 Top6 手风琴。
- **`/help/:slug`**：面包屑 + 正文排版 + 「本文有帮助吗？」（是/否，反馈收集）+ 相关文章 + **没解决？联系客服/申诉入口（合规）**。

## 22. `/search` 搜索结果

搜索框（保留关键词）→ 分组结果 Tab（全部/资讯/帮助/产品），条目=标题高亮+摘要+路径；空态给热门帮助与推荐文章。

## 23–27. 法律五页（模板统一）

窄栏排版（720px）：H1 + **更新日期 + 版本号** + 左侧**锚点目录**（滚动吸顶高亮当前节）+ 正文（层级标题、列表、表格）+ 文末联系方式/邮箱。
- `/legal/report` 额外：**在线投诉表单**（类型/链接/证明材料上传位/联系方式）+ 处理流程图（收到→下架→通知→反通知）+ 邮箱公示（合规要求）。
- 法律页要求：可打印、可复制全文、**注册勾选处均可点击直达**。

## 28. `/404`

居中插画（迷路宠物）+ 「你走丢了？」+ 返回首页/产品/帮助三按钮 + 搜索框；`noindex`。

## 29. `/c/:slug` Campaign 专题模板

运营生成的活动/分享落地页（L7 拉新链承接）：
1. 专属 Hero（运营配置主视觉/文案）
2. 内容模块组（图文块/数字块/视频位/评价块，运营自助拼装 6 种块）
3. 强 CTA（打开 Web/下载 + 参数透传）
4. 返回官网入口 + 合规页脚
- 规则：模板化配置，不开放任意 HTML；每期页 `noindex` 或按运营配置。
