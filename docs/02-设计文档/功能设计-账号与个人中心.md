# 功能设计 · 账号与个人中心（含家庭共享）

> 状态：评审中（闭环修订完成） · 版本：v1.3 · 更新日期：2026-09-22

## 1. 登录注册（A1）

```
触发（主动登录 / 登录闸门）→ 登录页（手机号 / 第三方渠道）
  → 首次注册：勾选《用户协议》《隐私政策》（默认不勾选）
  → 手机号：号码 → 验证码 → 年龄询问（方案甲·已决议）
      ≥14 岁 → 自动注册
      <14 岁 → 监护人同意流程（监护人手机号验证 + 展示儿童信息专门规则，监护人可撤销）
  → 登录成功 → 回跳原操作位（L1/L3 不断链）
  → 首次登录 → 养宠标签引导（可跳过）
```
- 登录态跨端互通（同一账号）；**异地/新设备登录 → 消息中心 + 推送安全提醒（一期做，已决议）**。
- 第三方账号绑定手机号：**仅同手机号合并账号**；不同手机号不合并并提示换号登录（已决议）。

## 2. 家庭组（A5 ⭐ · L9 链）

家庭管理员（初始创建者）、宠物所有者、共享成员、记录作者相互独立。每人一个家庭，每只宠物最多共享至所有者当前家庭；加入不自动分享自有宠物，新成员对已共享宠物默认只读。

管理员邀请/移除成员、转交管理或解散；所有者选择共享及成员档位，管理自己的宠物转移/归档/删除/恢复/导出。家庭管理员不取得他人宠物所有权。

完整权限矩阵与退出规则见BR-03/04：X03授权页、X04宠物转移、X05管理员转交。两种转移独立、24小时有效、双方核验；接受时再次检查资格。

成员离开其宠物回归私有，失去他人共享访问，历史贡献保留；解散不删除宠物。加入页只告知档案/记录/提醒/录入人，不开放私有收藏、草稿和报名。

## 3. 个人中心（我的）结构

```
我的
├── 我的宠物（列表，快捷切换/新建）
├── 家庭（创建/管理/邀请/加入）
├── 创作中心（文章/评测/清单/草稿/版本/数据，无作品仍可进入）
├── 活动中心（我的报名/我发布的/机构认证）
├── 待同步记录 / 宠物归档与回收站
├── 我的收藏：内容 | 商品 | 清单 | 场所 | 路线（分组 tabs）
├── 消息中心（H1）
├── 作者主页入口（我的主页）
└── 设置
    ├── 资料与养宠标签
    ├── 账号与安全（换绑/密码——若有）
    ├── 隐私设置（档案默认私有，主动选择共享宠物及授权成员；互动可见性）
    ├── 通知设置（提醒推送、互动通知的开关与免打扰时段）
    ├── 数据导出 / 注销账号
    └── 帮助与客服（FAQ / 联系表单 / 申诉入口 / 举报与版权通道）（新增·合规）
```

## 4. 消息中心（H1）

**分类 Tab**：🔔 提醒通知（B5）| 💬 互动（赞/评/关注）| 📝 审核结果 | 👨‍👩‍👧 家庭（加入/移除/共享变更）| ⚙️ 系统。

- 未读红点计数；全部已读；单条点击跳对应对象深链。
- 移动端：互动/审核/家庭消息可走推送（开关可控）；提醒通知独立走 B5 通道。

## 5. 注销与数据导出（A4）

设置→核验→依赖清单（家庭管理、自有共享宠物、活动、报名、转移）→解除/转移/取消→确认→15天冷静期→删除/匿名化。

管理员转交或解散；自有共享宠物可转移或解除共享后随账号删除，不强制找到接收者；归档不替代转移。冷静期登录显示显式撤销按钮，受限状态仍可查进度/申诉/提出信息请求；详细处置按BR-04/09。

JSON导出经验证码核验，含本人资料、自有宠物/记录、收藏/投稿/报名和同意记录。他人宠物仅含本人贡献字段与脱敏编号，不导出他人档案或名单。下载仅本人可用，24小时失效，重新下载仍核验并留痕。

## 6. 异常汇总

| 场景 | 处理 |
|------|------|
| 邀请码过期/失效 | 明确提示 + 请求新邀请 |
| 已在其他家庭还想加入 | **一人限一个家庭（已决议）**：提示先退出原家庭再接受邀请 |
| 注销冷静期内登录 | 核验后显式确认撤销，不自动撤销 |
| 撤回/移除即时生效 | 成员会话端下次鉴权即失效 |

## 7. 多端差异

- 移动端：推送授权引导、通知免打扰设置；家庭邀请通过分享卡片唤起 App/H5。
- Web：数据导出、隐私设置等低频操作主阵地；管理端账号体系独立（见管理端功能设计）。
