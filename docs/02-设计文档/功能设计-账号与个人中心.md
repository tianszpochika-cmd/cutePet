# 功能设计 · 账号与个人中心（含家庭共享）

> 状态：已定稿（上线合规修订 v1.2） · 需求追溯：A1–A5、A7、H1 · 版本：v1.2 · 更新日期：2026-09-22

## 1. 登录注册（A1）

```
触发（主动登录 / 登录闸门）→ 登录页（手机号 / 第三方渠道）
  → 首次注册：勾选《用户协议》《隐私政策》（默认不勾选）
  → 手机号：号码 → 验证码 → 年龄询问（方案甲·已决议）
      ≥14 岁 → 自动注册
      <14 岁 → 监护人同意流程（监护人手机号验证 + 展示儿童信息专门规则，监护人可撤销）
  → 登录成功 → 回跳原操作位（L1/L3 不断链）
  → 首次登录 → 养宠标签引导（可跳过）
```
- 登录态跨端互通（同一账号）；**异地/新设备登录 → 消息中心 + 推送安全提醒（一期做，已决议）**。
- 第三方账号绑定手机号：**仅同手机号合并账号**；不同手机号不合并并提示换号登录（已决议）。

## 2. 家庭组（A5 ⭐ · L9 链）

**生命周期状态机**
```
（用户）无家庭 → 创建家庭（命名+头像）→ 家庭存续
  → 生成邀请（链接/码：**有效期 7 天、不限使用次数，创建者可随时失效重置**——已决议）
  → 被邀请人接受 → 成为成员（**加入前若已在其他家庭，必须先退出——一人限一个家庭，已决议**）
  → 成员可退出；创建者可移除成员 / 解散家庭（解散=解除全部共享，二次确认）
```

**权限判定表（一期两档）**

| 动作 | 宠物所有者 | 成员·可管理 | 成员·只读 | 其他人 |
|------|:--:|:--:|:--:|:--:|
| 查看共享宠物档案/时间线 | ✅ | ✅ | ✅ | ❌ |
| 编辑档案、录入记录 | ✅ | ✅ | ❌ | ❌ |
| 处理提醒（完成/关闭） | ✅ | ✅ | ❌（仅可见） | ❌ |
| 收到提醒通知 | ✅ | ✅ | ⚪（只收不处理，可设置免打扰） | ❌ |
| 邀请/移除成员、解散 | ✅（=创建者） | ❌ | ❌ | ❌ |
| 宠物加入/移出家庭 | ✅ | ❌ | ❌ | ❌ |
| 查看对方私有数据（对方的收藏/投稿） | — | ❌ 各自私有 | ❌ | ❌ |

- 宠物所有权唯一；所有者退出平台（注销）→ 其共享宠物按注销策略处理（提前提示：先转移或归档）。
- 被移除成员：即时失去访问；已产生的贡献记录（如健康记录）保留并标注录入人。
- **加入页**：邀请深链 → 未登录先注册 → 确认加入 → 落到共享宠物详情。

## 3. 个人中心（我的）结构

```
我的
├── 我的宠物（列表，快捷切换/新建）
├── 家庭（创建/管理/邀请/加入）
├── 创作中心（撰写/草稿/投稿状态/数据）
├── 我的收藏：内容 | 商品 | 清单 | 场所 | 路线（分组 tabs）
├── 消息中心（H1）
├── 作者主页入口（我的主页）
└── 设置
    ├── 资料与养宠标签
    ├── 账号与安全（换绑/密码——若有）
    ├── 隐私设置（档案可见性=仅自己+家庭；互动可见性）
    ├── 通知设置（提醒推送、互动通知的开关与免打扰时段）
    ├── 数据导出 / 注销账号
    └── 帮助与客服（FAQ / 联系表单 / 申诉入口 / 举报与版权通道）（新增·合规）
```

## 4. 消息中心（H1）

**分类 Tab**：🔔 提醒通知（B5）| 💬 互动（赞/评/关注）| 📝 审核结果 | 👨‍👩‍👧 家庭（加入/移除/共享变更）| ⚙️ 系统。

- 未读红点计数；全部已读；单条点击跳对应对象深链。
- 移动端：互动/审核/家庭消息可走推送（开关可控）；提醒通知独立走 B5 通道。

## 5. 注销与数据导出（A4）

**注销流程**
```
设置 → 注销账号 → 校验 → 展示将失去的内容（宠物档案/家庭关系/投稿）
→ 确认 → 冷静期 15 天（可撤销）→ 期满：账号停用，数据按策略删除/匿名化
→ 家庭成员/被共享关系提示先行处理
```
- 有家庭宠物未处理 → 阻断并引导先处理（转移所有权/移出家庭）。
- 已发布 UGC 的处理：匿名化保留（社区内容连续性）或删除，待合规确认——**默认匿名化保留**。

**数据导出**：个人资料 + 宠物档案 + 健康记录，导出为 **JSON 文件**（已决议，格式机读完整）；导出请求记录留痕。

## 6. 异常汇总

| 场景 | 处理 |
|------|------|
| 邀请码过期/失效 | 明确提示 + 请求新邀请 |
| 已在其他家庭还想加入 | **一人限一个家庭（已决议）**：提示先退出原家庭再接受邀请 |
| 注销冷静期内登录 | 撤销注销 |
| 撤回/移除即时生效 | 成员会话端下次鉴权即失效 |

## 7. 多端差异

- 移动端：推送授权引导、通知免打扰设置；家庭邀请通过分享卡片唤起 App/H5。
- Web：数据导出、隐私设置等低频操作主阵地；管理端账号体系独立（见管理端功能设计）。
