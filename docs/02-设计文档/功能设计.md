## 2. 公共功能规范（全站复用）

### 2.1 通用组件行为
- **登录闸门**：未登录触发写操作 → 登录/注册 → 回跳原位继续操作。
- **二次确认**：删除、封禁、移除成员、归档宠物、驳回重提等高危操作必须二次确认。
- **表单校验**：即时校验 + 提交校验；错误提示定位到字段。
- **空/加载/错误三态**：所有列表与详情页必须定义三态展示。
- **审核状态徽标**：统一四色状态组件（草稿/待审/通过/驳回），全站一致。
- **Toast/消息中心**：操作结果 Toast；异步结果（审核、提醒）进消息中心。

### 2.2 全局状态机（共享定义）

**① 审核状态机**（内容提交版本适用；纠错、举报、版权、申诉使用独立工单状态）

```
提交版本：草稿 → 待审核 → 审核中 → 通过 / 驳回（附理由）/ 撤回
公开对象：未发布 → 已发布（引用通过版本）→ 作者撤下 / 治理下架
修改版本待审时旧线上版保留；通过后校验并切换，驳回不影响旧版。
```

**② 提醒计划与本次待办**

计划：草稿→启用⇄暂停→结束。
待办：未到期→待处理→逾期；可完成/跳过/取消。
本期终结后才生成唯一下一期，逾期仍可处理。排期基准、健康记录一致性与重试按BR-02。

**③ 纠错工单状态机**（探索）

```
用户提交 → 待处理 → ✅采纳（POI 信息更新+通知贡献者）
                  └→ ❌驳回（附理由+通知贡献者）
```

**④ 账号状态机**（管理端治理）

```
正常 →（违规）受限/封禁（定时限或永久）→ 解封 → 正常
正常 →（用户申请）注销冷静期 → 已注销（数据删除/匿名化）
```

### 2.3 字段与命名约定
- 所有记录含：创建时间、创建人、（审核对象）审核人/审核时间/意见。
- 时间展示：列表相对时间（3 分钟前），详情绝对时间。
- 体重单位默认 kg，支持切换斤（换算规则：1 斤 = 0.5 kg）。
- 删除策略：业务数据默认「软删/归档」，软删宠物30天与注销账号15天到期执行清理，治理清除按专门规则执行。

## 3. 端适配原则（功能层面）

- 各端在其功能范围内使用一致业务规则；官网只公开展示，管理端按内部权限操作，Web与移动用户能力对齐（详见交互设计）。
- 移动端额外：推送通道承载提醒；弱网时记录类数据允许「本地暂存→联网同步」（一期必备，失权、去重与冲突按BR-04）。
- 每个子文档末尾附「多端差异」节。
