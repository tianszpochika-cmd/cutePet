## 2. 公共功能规范（全站复用）

### 2.1 通用组件行为
- **登录闸门**：未登录触发写操作 → 登录/注册 → 回跳原位继续操作。
- **二次确认**：删除、封禁、移除成员、归档宠物、驳回重提等高危操作必须二次确认。
- **表单校验**：即时校验 + 提交校验；错误提示定位到字段。
- **空/加载/错误三态**：所有列表与详情页必须定义三态展示。
- **审核状态徽标**：统一四色状态组件（草稿/待审/通过/驳回），全站一致。
- **Toast/消息中心**：操作结果 Toast；异步结果（审核、提醒）进消息中心。

### 2.2 全局状态机（共享定义）

**① 审核状态机**（UGC 投稿、路线、活动、纠错采纳复用）

```
草稿 → 提交 → 待审核 → 审核中 → ✅通过 → 已发布 →（运营）已下架
                                  └→ ❌驳回（必附意见）→ 修改重提 → 待审核
```

**② 提醒状态机**（宠物管理）

```
待启用 → 已启用 →（到期触发）待处理 → ✅已完成
                                   ├→ 已过期（超时未处理）
                                   └→ 已关闭（用户关闭）
重复型提醒：已完成 → 自动排下次 → 已启用
```

**③ 纠错工单状态机**（探索）

```
用户提交 → 待处理 → ✅采纳（POI 信息更新+通知贡献者）
                  └→ ❌驳回（附理由+通知贡献者）
```

**④ 账号状态机**（管理端治理）

```
正常 →（违规）受限/封禁（定时限或永久）→ 解封 → 正常
正常 →（用户申请）注销冷静期 → 已注销（数据删除/匿名化）
```

### 2.3 字段与命名约定
- 所有记录含：创建时间、创建人、（审核对象）审核人/审核时间/意见。
- 时间展示：列表相对时间（3 分钟前），详情绝对时间。
- 体重单位默认 kg，支持切换斤（换算规则：1 斤 = 0.5 kg）。
- 删除策略：业务数据默认「软删/归档」，物理删除仅治理流程触发。

## 3. 端适配原则（功能层面）

- 同一功能四端共用同一套流程与状态机，仅交互载体不同（详见交互设计）。
- 移动端额外：推送通道承载提醒；弱网时记录类数据允许「本地暂存→联网同步」（一期建议支持，交互阶段细化）。
- 每个子文档末尾附「多端差异」节。
