01 / 03 · 新手养宠

刚把它接回家，先把重要的事记清。

不用一次记住所有细节。先建立档案，再把已有健康信息和下一次计划放到同一条照护路径里；有疑问时按频道寻找参考内容。

情境问题

  • 疫苗、驱虫、体检等信息散在照片和聊天里。
  • 想知道上次什么时候做过，下一次该何时提醒。
  • 需要知识参考，但不想把科普当成诊疗建议。

可执行的四步

示意流程 · 由用户在应用内完成
  1. 01建立宠物档案

    填写昵称、物种、生日或年龄等基础信息，之后可继续补全。

  2. 02补上健康记录

    按实际发生时间记录疫苗、驱虫、体检或就医事件。

  3. 03安排下次提醒

    选择单次或周期计划，未来日期与已有计划的关系由用户确认。

  4. 04按主题查资料

    从七个资讯频道寻找内容；涉医内容仅供科普参考。

02 / 03 · 多宠家庭

照顾的不止一只，事情也能各自清楚。

每只宠物保留独立档案和安排；需要家人接力时，先明确哪些档案共享、谁可以处理提醒，完成后看得到处理人。

情境问题

  • 多只宠物的记录容易串在一起。
  • 同一件待办可能被两位家人重复处理。
  • 希望家人协作，也要保留未共享档案的私密性。

可执行的四步

示意流程 · 由用户在应用内完成
  1. 01分别建立档案

    为每只宠物保存基础信息、健康记录与提醒计划。

  2. 02查看各自待办

    切换宠物，确认下一件事属于哪只宠物。

  3. 03按范围邀请家人

    只共享需要协作的宠物，并明确可管理或只读权限。

  4. 04交接后核对进度

    处理状态标记处理人，避免重复完成；权限变更后按新权限生效。

对应的产品能力

共享有范围，权限逐动作
宠物管理多宠档案与计划

按宠物分别浏览时间线、体重记录及提醒。

家庭共享可管理或只读

新成员默认只读；未共享的个人宠物对家人不可见。

所有者权限关键操作有边界

健康摘要和所有权转移等敏感操作由所有者处理。

03 / 03 · 带宠出行

出门前，先看看哪里适合一起去。

从城市和场所条件开始，查看详情、路线与活动信息。路线与评价是参考，是否适合带宠仍需结合现场规则自行判断。

情境问题

  • 不知道附近有哪些允许带宠的场所。
  • 想提前核对设施、营业信息与遛宠路线。
  • 看到活动后，需要了解报名条件与信息使用方式。

可执行的四步

示意流程 · 不虚构场所或活动数据
  1. 01确定城市与条件

    允许定位时查看附近；未授权时改为手动选择城市。

  2. 02核对场所详情

    按类型及宠物友好属性筛选，再查看设施与营业信息。

  3. 03参考遛宠路线

    浏览公开路线的起终点、距离与难度，出门前再核对现场条件。

  4. 04了解活动再报名

    先看活动信息；进入用户端后阅读告知并单独同意，再确认报名。

对应的产品能力

公开信息与用户操作分开
宠物探索场所筛选与详情

地图/列表、位置兜底、设施标签与信息纠错。

宠物探索路线与本地活动

查看公开路线；活动报名回用户端确认。

宠物资讯出行前的内容参考

阅读相关公开内容，不把文章或评价当成到店保证。
