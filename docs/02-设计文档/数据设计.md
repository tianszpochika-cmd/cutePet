# 数据设计 · 业务概念与关系

> 状态：评审中（闭环修订完成） · 版本：v1.3 · 更新日期：2026-09-22

本文描述业务对象，不指定数据库/框架。详细状态见 [业务规则与生命周期](../01-需求文档/需求-业务规则与生命周期.md)，统计见 [指标与验收口径](../01-需求文档/需求-指标与验收口径.md)。

## 1. 账号与家庭

- 用户：正常/受限/封禁/注销冷静期/已注销；手机号与第三方身份绑定、协议版本同意、实际周岁依据、受限身份能力。
- 监护同意：儿童用户、监护联系身份、规则版本、同意/撤回时间与核验记录；不可仅靠家庭成员关系推导。
- 家庭：一个当前管理员、多名成员；成员最多属一个家庭。管理员转交为独立双向确认申请。
- 宠物：唯一所有者，最多一个共享家庭；所有者须属于该家庭。共享授权 = 宠物×成员×档位，非家庭×宠物上的统一权限。
- 宠物转移申请：原/新所有者、对象版本、24h期限、接受/拒绝/撤销/失效结果，与管理员转交分开。
- 档案状态：有效/归档/软删/已清理；共享撤销不删除所有权，成员贡献录入人留痕。

## 2. 照护与通知

- 健康记录：体重、疫苗、驱虫、体检、就医、用药、过敏；分别有发生日期或不详标记、录入者、附件和更正历史；过敏有效性与用药进行中状态独立于记录日期。
- 提醒计划：宠物、类型、周期、基准、时间、状态；一个计划多个历史待办但最多一个未终结待办。
- 待办：唯一执行编号、计划到期时间、状态、处理者、确认时间、关联健康记录或说明；完成不覆盖旧实例。
- 记录保存与待办完成为同一业务结果，重试不能产生第二次结果；新记录关联现有计划时不自动创建副本。
- 通知：待办/业务事件、接收者、类型、有效期；发送尝试、渠道接受、送达回执和打开分开。未知回执不是成功送达。
- 离线草稿：账号与宠物归属、唯一提交标识、同步状态；权限失效时不升级为服务端健康记录。

## 3. 内容与探索

- 内容对象：文章/评测/清单/路线/活动/领养等公开对象，各有公开状态与线上版本引用；每个提交版本绑定独立审核记录，待审版不是线上版。
- 评测：关联商品、来源类型/证据、利益关系；健康内容有专业复核记录。清单商品关系有顺序、推荐理由。
- 商品：允许品类、标签、上下架与治理原因；普通下架和治理清除影响不同的引用展示。
- POI：位置、类型、营业信息、数据来源、最后核验时间；纠错工单关联对象及变更字段。
- 评价：三项评分、正文/图片、可见状态、计分资格、风险原因及审核记录；公开有效才参与评分。
- 机构认证：申请主体、私有核验材料、联系人、有效期、审核/复核、直发资格状态；与C端用户身份关联，不视为管理端角色。
- 活动：线上版本、运行状态、开始/结束/截止、名额、组织者；报名绑定提交时版本、接收方和同意凭证。
- 报名：账号×活动最多一条有效报名，历史取消/重报名保留独立编号；名额、报名成功一致生效；姓名电话带清理截止时间。
- 领养：独立信息对象、无偿声明、联系方式公开同意、人工审核、30天有效确认；无报名/订单实体关系。

## 4. 治理、导出与统计

- 举报、版权、申诉、一般客服为独立工单类型；处置记录与申诉分离，一次处置可有受规则约束的补充材料及复核历史。
- 审计记录只对获授权角色可查；记录前后值时不复制所有敏感健康/个人信息到无期限通用日志。
- 导出任务：申请人、核验时间、对象范围、状态、下载有效期；不能因为属于家庭就导出他人完整档案。
- 清理任务：账号/宠物/报名/文件对象、截止时间、状态、失败原因、复核；失败进入运营待办，不以“已标记过期”代替删除。
- 指标事件：环境、口径版本、最小必要主体和对象编号、业务结果；与生产记录分层授权，排除模拟数据。

## 5. 必须维护的关系不变量

1. 当前家庭管理员唯一、宠物所有者唯一，不能由同一个字段同时表示两种身份。
2. 共享授权依赖当前成员和有效宠物，移除/解散/归档/删除后访问和触达同时失效。
3. 已完成待办只能有一个有效完成结果及一个后继待办；不得重试后复制健康记录。
4. 公开版本必须对应有效审核/授权直发依据；旧审核结果不适用于新正文。
5. 有效报名不超过名额且账号活动唯一；数据提供对象和同意凭证关联到报名时版本。
6. 账号注销清理、宠物软删恢复、治理证据保留是不同生命周期，不能共用单一删除开关。
