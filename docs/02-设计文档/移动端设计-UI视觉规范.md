# 移动端设计 · UI 视觉规范

> 状态：评审中 · 版本：v1.0 · 更新日期：2026-09-22
>
> 与 `官网设计-UI视觉规范.md` 同源令牌（全端视觉统一），本文定义**移动端专属**规格。
> 关键词：可爱 / 温暖 / 可信；一期**仅亮色模式**（暗色不做，见 §7 决议）。

## 1. 设计令牌（移动端基准）

**色彩**：与官网完全一致 —— `--primary #FF7A2F`、`--primary-soft #FFF1E8`、`--ink #2B2118`、`--ink-2 #7A6E63`、`--line #F0E6DC`、`--bg #FFF9F3`、`--surface #FFF`；模块色：管理橘 / 资讯粉 `#FF5C7A` / 探索绿 `#2FBF71` / 用品蓝 `#4D8DFF` / 家庭紫 `#9B8CFF`；语义色同官网。

**字号**（基准 375pt，支持系统字号缩放不破版——用 sp/相对单位）：

| 层级 | 值/行高 | 用途 |
|------|---------|------|
| Display 30/1.3 700 | | 引导页大标题 |
| H1 24/1.35 700 | | 页面标题（导航栏下大标题场景） |
| H2 20/1.4 700 | | 分节标题 |
| H3 17/1.45 600 | | 卡片标题 |
| Body 15/1.7 400 | | 正文 |
| Caption 13/1.5 400 | | 辅助、时间戳 |
| Micro 11/1.4 500 | | Tab 标签、角标 |

**间距**：4 基数（页边距 16，卡片内边距 16，区块间距 24–32）。
**圆角**：卡片 16 · 输入/按钮 12 · 胶囊(chip/Tab) 999 · 弹层顶 20 · 大面板 24。
**阴影**：移动端收敛——卡片默认无投影（靠描边 `--line` 1px + 底色区分）；浮层用 `0 -8px 24px rgba(43,33,24,.08)`（向上投影）。

## 2. 布局与安全区

- 基准宽 375，向下 320 兼容（关键按钮不截断），向上自适应拉伸间距。
- **安全区**：`env(safe-area-inset-*)` 全覆盖——刘海屏顶部导航内边距、底部 Tab/操作条 home indicator 内边距、弹层底部按钮组。
- 单手可达原则：**主操作固定在下 1/3**（底部按钮条、悬浮主按钮、底部 Tab）；顶部只放浏览型操作（返回/搜索/更多）。

## 3. 导航组件

### 3.1 底部 Tab Bar（4-Tab 决议）
- 高 56 + 安全区；白底 + 顶部 1px `--line`；激活态：图标填充 + 文字 11/600 + 模块色？——**统一用主橘色激活**（避免四色争抢，模块色留给内容页内）。
- 角标：消息红点/数字（我的），提醒蓝点（首页）。
- 切换反馈：图标轻微上弹（见动效规范）。

### 3.2 导航栏（二级页）
- 高 44 + 状态栏；透明吸顶 → 下滚 8px 后浮出白底+底线。
- 结构：左返回（44×44 chevron）/ 中标题（17/600，超长省略）/ 右操作（最多 2 个，多于 2 收进「更多」圆点菜单）。
- **大标题页**（首页/资讯/探索/我的根页）：不用导航栏标题，页面内 H1 24 起排。

### 3.3 面包屑/步骤条（建档向导）
- 顶部进度：4 段等分条（完成段主橘）+ 步骤名；左右滑动手势切换步（带未保存拦截）。

## 5. 地图场景专属

- 地图占屏 65%，顶部搜索条浮层（白胶囊 + 阴影）；筛选按钮右侧悬浮（激活态橘）。
- **POI 钉**：36×44 气泡（模块色底 + 白图标 + 下尖角 + 投影）；选中放大 1.15 + 白描边；聚合点圆形数字。
- 底部列表卡：横滑 86% 宽卡，与地图选中联动高亮（描边变橘）。

## 6. 表单与键盘

- 单列表单，标签上置；提交按钮吸底（键盘弹出时贴键盘上方）。
- 键盘类型匹配（数字体重用数字键盘+小数点）；输入框聚焦自动滚入可视区。
- 即时校验在失焦时触发，错误=红描边+字段下 13 红字。

## 7. 一致性与降级决议

- **一期仅亮色**（已决议）：不做暗色模式；系统暗色下保持亮色，导航栏/Tab 用白底适配。
- **动态字号**：跟随系统字体缩放，布局用相对高度，标题两级以内自动缩（超限截断省略）。
- **低端机降级**：动画降级见动效规范 §6；图片统一 WebP（iOS 兼容层）+ 懒加载占位。
- 图标：2px 圆头线性 24 网格，同族同重；Tab 激活用填充版双态图标。
