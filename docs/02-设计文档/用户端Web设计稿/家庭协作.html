01 / 角色预览

同一个家庭，不同的可见范围。

试着切换三位成员。宠物清单、本人档位与可操作入口会同步变化；家人的其他授权档位只由对应宠物所有者管理。

切换仅改变本地示例画面，不会切换真实账号、修改授权或保存记录。

02 / 权限解释

“可管理”，
也有清楚的边界。

家庭管理员负责成员与家庭；宠物所有者负责该宠物的授权。管理某只宠物的记录，不代表可以导出摘要、解除共享或转移所有权。

03 / 邀请前告知

先讲清共享什么，
再邀请家人。

加入家庭只是建立成员关系。现有已共享宠物对新成员默认只读；每只宠物的所有者仍负责授权。受邀人的自有宠物、收藏和私有互动不会自动开放。

✦ 发送邀请前要让对方知道

能看见的，与继续私有的

  • 已共享宠物的档案、健康记录、时间线、提醒及录入人，按本人档位查看。
  • 未共享宠物仍只对所有者可见；家人不能因管理员身份越权。
  • 个人收藏、草稿、联系方式和报名信息不随家庭关系开放。

04 / 关键转移

两种转移，两次独立确认。

所有权与家庭管理权不同。下方只解释步骤和影响，不提供模拟提交或成功反馈。

🐾

宠物所有权转移

由当前宠物所有者发起，选择同家庭且符合条件的接收者。双方分别核验，24 小时内待接受；接受前原所有者仍负责。完成后原所有者变为只读，其他可管理授权降为只读，历史处理人不变。

入口定位：该宠物资料的危险操作区
⌂

家庭管理员转交

由当前家庭管理员发起，与任何宠物所有权转移分开。双方确认前原管理员继续有效；接收者确认后才变更家庭管理权，也不会因此得到他人宠物的额外权限。

入口定位：家庭管理设置
成员退出或被移除后，失去其他共享宠物的访问；其自有宠物解除家庭共享但仍归本人所有。归档或删除宠物会解除共享并暂停后续计划；恢复时须重新确认共享对象与未来提醒。

邀请前的共享告知

受邀人加入后，可以按本人档位查看家庭内已共享宠物的档案、健康记录、时间线、提醒和录入人。新成员默认只读。未共享宠物不会出现；收藏、草稿、私人联系方式及报名信息也不会开放。

  • 家庭管理员可以邀请成员，但不能替其他宠物所有者提升共享档位。
  • 邀请链接按需求有效 7 天；具体链接和到期时间应由真实服务返回。
  • 受邀人登录后须再次核对家庭信息并确认加入，不会因为打开链接自动加入。
邀请卡片示意邀请加入「我们的家」 · 新成员默认只读 · 正式邀请码与有效期需由平台生成。此处不提供复制、发送或真实提交。
