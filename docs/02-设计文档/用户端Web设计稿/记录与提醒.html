提醒如何送达

  • 本页只展示站内待办和排期预览；系统通知能力以实际环境与授权结果为准。
  • 家人按当前共享权限与各自通知偏好查看提醒；只读成员不能处理待办。
  • 计划暂停与跳过本次是不同操作；逾期待办仍可处理。

日期规则采用北京时间。示例不构成接种、用药或诊疗建议；周期由用户自行确认。
