# cutePet 用户端 Web 全站页面蓝图

> 状态：设计方案，待逐页评审 · 版本：v0.1 · 日期：2026-09-23
> 范围：当前 Web 路由的信息组织、页面目标、关键状态与跨页任务链。本文件补充四份 HTML 交互稿，**不表示页面已实现完整业务、接入真实服务或通过验收**。

本文以[当前 Web 路由表](../../../apps/web/src/router.ts)为路径基准，以[信息架构](../信息架构.md)、[交互设计](../交互设计.md)、[闭环页面与状态](../功能设计-闭环页面与状态.md)和[本轮评审说明](评审说明.md)为行为依据。路由表目前定义 **53 条明确业务路径和 1 条兜底路径**；动态段 `:id`、`:slug`、`:doc` 是模板参数，不代表已有可公开的实例。信息架构中提出但路由表没有独立路径的能力，在下文标为**待定入口或复用页面**，不能凭本蓝图当作已可访问地址。

## 1. 导航与页面层级

桌面顶部一级入口是「首页｜宠物管理｜资讯｜探索｜用品」，右侧提供消息、家庭和登录/个人中心。首页优先呈现本人待办和宠物；资讯、探索、用品作为次级发现入口。游客可以阅读可公开内容；建档、记录、互动、报名、投稿和家庭操作须经过登录及逐动作权限检查。登录后应回到来源对象与原确认位置，发布、报名、加入、删除等仍需用户再次确认。

```text
首页 /
├─ 宠物管理 /pets → 建档 /pets/new → 详情 /pets/:id
│  ├─ 健康记录 /pets/:id/record · 体重 /pets/:id/weights
│  ├─ 提醒 /pets/:id/reminders → 计划 /plans/:id → 待办确认 /todos/:id/confirm
│  ├─ 共享 /pets/:id/share · 转移 /pets/:id/transfer · 回收站 /pets/recycle
│  └─ 家庭 /family → 邀请 /family/invite · 加入 /family/join · 管理员转交 /family/transfer-admin
├─ 资讯 /news → 文章 /news/:slug · 搜索 /search
│  └─ 创作 /write · 投稿 /submissions · 清单 /write/list/new · 版本 /submissions/:id/version
├─ 探索 /explore → 场所 /explore/poi/:id → 评价 /explore/poi/:id/review
│  └─ 路线 /explore/routes · 活动 /events
├─ 用品 /goods → 商品 /goods/:id · 清单 /lists/:id
└─ 我的 /me → 收藏 /me/favorites · 活动中心 /me/activity-center · 消息 /messages
   └─ 设置 /settings · 帮助 /help · 规则 /legal/:doc · 受限服务 /blocked
```

图中保留主路径以便读懂层级；下表列出全部路由。多端共享数据，但本稿只规定用户端 Web 的页面和状态。官网负责公开介绍与引流，不能在官网直接完成用户写操作。

## 3. 各组关键状态与页面动作

每个列表或详情至少定义**加载、空、错误**；私有对象另定义**无权限/失效**；每个写操作另定义**校验、提交中、成功、失败与重复提交**。以下是下一轮逐页稿必须画出的具体状态，不代表现有代码均已具备。

| 页面组 | 游客与首次空态 | 加载、错误、无权限或失效 | 提交结果与下一步 |
|---|---|---|---|
| 首页、宠物列表/详情 | 游客看公开入口，私有卡不填演示用户数据；无宠物引导主动建档，无待办保持平静空态；草稿可「继续完善」 | 宠物和待办各自骨架；失败保留标题及重试；私有详情撤权后先拒绝再渲染，不泄露姓名、照片或记录 | 建档仅在平台保存确认后进入详情；记录仅在确认后进入时间线，体重才更新曲线 |
| 登录与监护 | 协议分别默认未勾选；游客拒绝可继续有限公开浏览；新用户显示年龄询问 | 手机号、验证码、协议、年龄分别校验；发送失败和错误码可重试；未满 14 周岁独立监护核验失败时提供帮助/人工入口 | 登录成功回到原对象与动作位；监护人同意不能由儿童端假设成功；高影响操作回跳后重新确认 |
| 健康记录、提醒、计划与同步 | 无记录引导第一条；无计划引导主动创建；无待办明确当前没有待处理事项 | 表单失败保留输入；离线只显示「待同步」；计划/待办加载与错误分开；权限变化清理受控副本；家人先处理时刷新当前结果 | 健康类待办须关联有效记录，本次完成和记录保存同成同败；成功展示处理人、实际记录、下一期；推送仅写已验证的渠道状态 |
| 资讯、搜索与创作 | 游客可读已发布内容；空 Feed/搜索给出更换词或频道；创作无作品仍保留入口 | 草稿/驳回/下架不作为公开卡片；失效分享解释原因；编辑器自动保存失败可重试，保留输入；作者仅见本人投稿状态 | 点赞/收藏/评论回跳原文；提交审核显示「待审核」而非「已发布」；版本替换只在当前提交版本审核通过后生效 |
| 探索、场所、路线与活动 | 拒绝定位可手动选城市；稀疏城市和无活动显示真实空态；领养信息没有报名按钮 | 地图失败降级列表；POI/活动下架或结束给原因；评价无权限/频控明确；报名满员、截止、取消及变更分别显示 | 活动报名须展示告知后确认，报名详情可查编号/状态；导航按钮只表示尝试调起地图，不宣称已到店 |
| 用品与清单 | 游客可看可公开的资料、评测、清单；无内容不填虚构价格/库存/排行 | 商品下架、清单商品失效要指出哪些项不可用；资料加载失败保留返回入口；收藏前检验登录 | 收藏展示平台结果；评测注明来源、证据与利益关系；没有购物车、订单、支付或站内购买流程 |
| 家庭、共享与转移 | 无家庭可创建或处理邀请；加入前看共享范围；新成员默认只读，自有未共享宠物仍私有 | 仅本人可见的授权信息才展示；失效/过期邀请、已在其他家庭、被撤权、转移逾期和接收资格变化各有说明；拒绝私有深链不先闪出数据 | 邀请码由平台生成，加入需本人确认；宠物所有权与管理员转交分别由双方核验，待接受不提前改权，失败保留原权属 |
| 我的、消息、活动中心 | 无收藏、报名或作品时各给明确入口；游客进入个人能力先经登录闸门 | 消息加载、已读失败及目标已失效要有可返回结果；普通用户不能查看别人的报名名单；受限账号不能进入普通个人中心 | 活动发布后显示审核或已发布真实状态；取消/变更通知分别显示创建、投递与失败状态，不混成「已送达」 |
| 设置、帮助与规则 | 游客仍可读可公开的规则与帮助；正式文本显示版本和生效日期 | 导出、注销、监护控制、申诉先核验身份；账号依赖、冷静期和失败状态要可追踪；受限用户保留申诉与信息请求 | 导出链接仅本人可用且有有效期；注销需展示宠物、家庭、活动等依赖，冷静期登录须显式撤销确认 |

## 4. 跨页闭环与交接点

1. **L1 首次使用**：任意公开页触发写操作 → `/login`、验证码、首次年龄判断与必要的监护人流程 → 安全回跳原操作 → `/pets/new` 四步建档 → 平台确认后进入 `/pets/:id` → 首条记录 `/pets/:id/record` → 提醒 `/pets/:id/reminders`。中途退出保留草稿；回跳不自动提交加入、报名或发布。
2. **L2 日常照护**：首页待办或宠物提醒 → `/plans/:id` 看周期和历史 → `/todos/:id/confirm` 选择已有记录或新增记录 → 确认发生日期及下一期 → 平台同时确认记录与本次处理 → 家人视角看到处理人和同一结果。保存失败保留输入；他人已完成则展示最新结果且不重写。离线转 `/me/sync` 查看真实同步状态。
3. **L3–L4 阅读到创作**：`/news` 或 `/search` → `/news/:slug` → 互动时登录并回原文；投稿从资讯/我的进入 `/write` → `/submissions` 看草稿、待审、发布、驳回 → `/submissions/:id/version` 对比修改稿。公开阅读只用仍可见的已发布版本。
4. **L5 探索与活动**：`/explore` 选择城市/筛选 → 场所详情与评价；路线从 `/explore/routes` 进入。`/events` 进入活动信息、报名告知和确认后，在 `/me/signups/:id` 与活动中心查询。当前没有活动详情的独立 Web 路由，下一轮先定承载页及分享深链。领养只提供联系/举报，不复用活动报名动作。
5. **L6 用品参考**：首页或 `/goods` → `/goods/:id` 看参数、来源清楚的相关评测 → 文章或 `/lists/:id` → 收藏并回到 `/me/favorites`。商品变更/下架时，评测和清单内的旧引用须同步显示可用状态；全链无站内交易。
6. **L9 家庭协作**：宠物详情 → `/pets/:id/share` 核对逐宠物授权；家庭管理员从 `/family/invite` 先展示告知再生成邀请；受邀人 `/family/join` 登录、核对家庭和默认只读后确认。转移所有权 `/pets/:id/transfer` 与转交管理员 `/family/transfer-admin` 是两条独立流程，双方核验、到期和撤销状态不能合并。
7. **X08–X16 账户与活动收尾**：活动中心负责发布、报名查询、变更取消与消息；设置负责导出、注销依赖与冷静期；`/blocked` 和 `/guardian/control` 让受限用户及监护人在普通登录之外仍能完成获准服务。每条链都要保留原任务、可查看结果和安全返回入口。

## 6. 交付判断
