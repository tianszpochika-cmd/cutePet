# 功能设计 · 管理端

> 状态：已定稿（上线合规修订 v1.2） · 需求追溯：管理端需求全量（含 2.8 内容安全 / 2.9 举报版权） · 版本：v1.2 · 更新日期：2026-09-22

## 1. 审核工作台 ⭐（UGC 一期核心）

**统一队列模型**（复用总纲审核状态机①）
- 队列类型：投稿文章 / 遛宠路线 / 活动发布 / 评价（抽审+举报）/ 评论（疑似）/ **图片与账号信息疑似（新增·内容安全）** / **举报工单 / 版权通知与反通知 / 申诉（新增·合规）**。
- 列表字段：类型、标题摘要、提交人、提交时间、等待时长（超 24h 标红）、举报数。
- 详情页：内容预览 + 提交人历史（违规记录摘要）+ 操作区。

**操作**
```
✅ 通过（可选附言） / ❌ 驳回（必附意见，支持常用意见模板快捷输入）
🔁 标记处理中（多人协作防重） / 📌 加急 / 🚫 暂停该用户投稿资格
```
- 操作留痕：审核人、时间、意见全量入审计日志。
- 批量：同模板批量通过（低风险类型）/ 批量驳回；批量操作二次确认。

## 2. 内容运营

- 文章管理：筛选（状态/频道/作者/时间）、编辑、下架（必填原因，作者收消息）、置顶、定时发布。
- 评论与举报：举报队列（内容/用户/场所合并队列）、删除评论、屏蔽用户。
- 分类标签：两级分类 CRUD、标签合并（防重复标签）。
- 推荐位/Banner：位管理 → 排期（起止时间）→ 关联内容 → 上下线；首页 feed 的专题/置顶配置。

## 3. 商品导购运营（方案 A）

- 商品库：CRUD（字段见用品功能设计§1）、**CSV 批量导入（一期支持，已决议）**、上下架。
- 关联维护：为评测绑定商品、创建运营清单、清单排序。
- 巡检任务：久未更新的参考价提醒（看板角标）。

## 4. 探索运营

- **POI 管理**：地图+列表双视图管理、增删改、停业标记、属性标签维护；前端用户纠错入口直达对应 POI。
- **纠错工单**（状态机③）：待处理列表（同类合并）→ 采纳（直接回写 POI 字段）/ 驳回（附理由）→ 双向通知。
- **评价抽审**：待审评价 + 被举报评价；隐藏处理对全站生效。
- **路线审核**：先审后发队列（复用审核工作台）。
- **活动/领养**：发布（运营直发）、审核（机构/用户提交）、结束标记；报名信息查看与导出（站内表单收集的数据）。

## 5. 用户与家庭治理

- 用户管理：查询（昵称/手机号脱敏显示）、详情（登录/投稿/评价/违规摘要）。
- 封禁（状态机④）：选择原因与期限 → 二次确认 → 执行（登录受限+内容隐藏策略）→ 通知用户 → 解封。
- 投稿资格暂停/恢复：配合审核工作台操作。
- 家庭纠纷处理：查看家庭成员关系（最小必要信息）、按申诉执行移除/恢复（操作留痕）。

## 6. 角色权限（RBAC · ✅ 细粒度权限点制已决议）

**原则**：一切操作皆权限点；预置角色 = 权限点集合；**支持自定义角色**（系统设置中按权限点自由勾选）。

### 6.2 角色规则

- **预置 6 角色**即上表列集合；可在其上复制修改生成自定义角色。
- **自定义角色**：按权限点勾选组合；权限点可授予任意角色。
- **高危双保险**：#24 封禁、#31 权限管理、#32 系统设置的操作均需二次确认 + 全量审计；#31/#32 仅能授予「管理员」类角色。
- 「管理员」角色不可被编辑或删除；每个管理员账号必须归属一个角色；权限变更即时生效并写审计。
- 原则：治理高危能力（封禁、权限分配）收敛到主管/管理员，一线运营无权。

## 8. 触达与审计

- 触达管理：提醒/通知模板（文案、渠道开关）、发送记录与失败率；**一期无营销群发**。
- 审计日志：操作者、时间、**IP（已决议：记录）**、对象、动作、前后值摘要；支持按类型/人员筛选。
- 高危操作二次确认清单：封禁、解散关联、批量下架、权限变更、物理删除。

## 9. 多端差异

- 管理端仅桌面 Web（一期不做移动管理端，**不做响应式兜底——已决议**）；非桌面浏览器访问时明确提示「请在电脑端使用」。

## 10. 内容安全与治理工作流（新增·合规，对应需求 2.8/2.9）

- **机审接入层**：文字过滤、图片审核（封面/评价图/路线活动图/头像）、账号信息校验 → 命中「疑似」进复审队列，机审不直接处罚。
- **词库管理**：敏感词库增删改 + 版本记录（归 system.settings），变更写审计。
- **处置执行**：按 L1–L4 阶梯（删内容/禁言 7·30 天/永久封禁）→ 二次确认 → 通知用户（附依据与申诉入口）→ 记录处置实体。
- **举报/版权工单**：举报 ≤48h、版权通知即下架再核查、反通知 ≤7 天；工单状态全量可查，结果回通知举报人/权利人。
- **申诉队列**（#27）：处置对象申诉 → 复核 → 恢复/维持，≤48h 反馈。
