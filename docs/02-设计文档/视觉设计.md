### 2.3 间距 / 圆角 / 阴影

- 间距 4 基数：4·8·12·16·24·32·48·64·96·128（移动页边 16，桌面内容宽 1200、正文窄栏 720）。
- 圆角：小 8 · 输入按钮 12 · 卡片 16–20 · 大面板 24–28 · 胶囊 999。
- 阴影三级：`sh-1 0 2px 8px/6%` · `sh-2 0 12px 32px/10%` · `sh-3 0 24px 64px/14%`；移动卡片默认无投影（描边区分），浮层向上投影。
- 断点：`≥1200 / 768–1199 / <768`；基准宽 375（移动）、1200（桌面）。

## 4. 图标与插画风格（全端统一）

- **图标**：2px 圆头线性、24 网格、同族同重；Tab 用填充/线性双态（激活填充）；模块图标着模块色；管理端同族（密度场景 20 网格）。
- **插画**：圆润扁平 + 轻渐变，宠物 IP 头身比约 1:1.5；装饰元素库（爪印/骨头/定位针/爱心）。
- **空态三件套**（全端统一画风）：迷路（404/无结果）、打盹（加载/无数据）、好奇（引导首次使用）。
- **情绪板（Moodboard）关键词**：奶油底色、超大圆角、真实宠物温暖侧光摄影、手绘爪印笔触、绒毛质感点缀——供品牌名确定后做正式 moodboard 与 Logo 提案。
- **截图规范**：产品 Mockup 统一 12° 展示台 + 柔投影（官网）/ 直角卡片（移动）；**UGC 图片禁用于官网/宣传**。

## 5. 管理端视觉补充（密度与效率）

- 桌面效率优先：字号基准 Body 14（列表）、行高 1.5；表格斑马纹 + 表头吸顶；卡片间距 16（比 C 端更紧）。
- 色彩克制：白/灰为主，橘只用于主按钮与告警高亮（>24h 标红、>48h 标紫）；危险操作红。
- 组件复用 C 端令牌，圆角降为 8–12（工具感），阴影仅用于抽屉/弹窗（sh-3）。

## 6. 暗色模式

- **一期不做**（已决议）：全端保持亮色；系统暗色环境下以亮色呈现，导航/Tab 白底适配。二期按需启动（预留：全部颜色走令牌，切换成本受控）。

## 7. 无障碍总纲（强制，分册细化执行）

| 项 | 标准 |
|----|------|
| 对比度 | 正文 ≥4.5:1，大字/图形 ≥3:1（WCAG AA） |
| 触控/点击区 | ≥44×44（移动）/ ≥40×40（Web） |
| 字号缩放 | 支持系统字号 200% 不破版（相对单位） |
| 键盘 | 全交互可达 + 可见焦点环（2px 橘 + 2px 偏移）；Tab 序=视觉序 |
| 语义 | 每页唯一 H1、landmark、图片 alt、装饰 aria-hidden |
| 动效 | `prefers-reduced-motion` 降级（见两套动效规范 §降级） |
