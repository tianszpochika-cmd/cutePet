# 移动端设计 · UX 与逐屏规格（从登录到所有功能）

> 状态：评审中（闭环修订完成） · 版本：v1.1 · 更新日期：2026-09-22
>
> 基础编号对齐 `移动端设计-页面架构.md` #1–57，补充页面/状态X01–X16见《功能设计-闭环页面与状态》。每屏给出 **结构 → 交互 → 状态**。
> 全局规则：① 所有写操作过登录闸门并回跳；② 列表页下拉刷新 + 触底分页（骨架屏）；③ 空态=插画+主按钮引导；④ 表单即时校验、丢失输入拦截；⑤ 触控目标 ≥44px。

## A. 启动与认证流（L1 激活链）

### A1 启动页（#1）
- 结构：品牌 Logo + 后台预加载（≤1.5s）。交互：静默跳转。状态：异常 → 错误页重试。

### A2 隐私同意弹窗（#2 · 首次）
- 结构：说明卡（收集什么/为何）+《隐私政策》《用户协议》链接 + 主按钮「同意并继续」+ 次按钮「不同意」。
- 交互：链接可点开全文（阅读模板）；不同意可进入不启用可选采集的游客浏览；私人写操作再申请必要同意，范围按BR-09。

### A3 登录页（#3）
- 结构：品牌插画 → 手机号输入（11 位格式即时校验）→ **协议勾选区**（默认不勾选，两个协议可点开；未勾选点登录 → 字段上方红字提示）→ 主按钮「获取验证码」→ 微信登录（分隔线「或」）。
- 交互：手机号输入自动带出 +86；微信按钮拉起授权（已装微信/未装降级为手机号）。
- 状态：风控倒计时、频率限制提示、网络错误重试。

### A4 验证码页（#4）
- 结构：手机号回显 +「更换」、6 格输入（键盘自动聚焦，粘贴支持）、倒计时重发（60s）、错误抖动→清空重输。
- 流程分支：**老用户 → 登录成功 → 回跳原位**；**新用户 → #5 年龄询问**。

### A5 年龄询问（#5 · 方案甲）
- 结构：完整出生年月日选择，按北京时间计算实际周岁；说明文案（为未满 14 岁用户提供监护人流程）。
- 交互：选 ≥14 岁 → 直接注册完成；选 <14 岁 → 推入 #6。

### A6 监护人同意流程（#6）
- 结构：说明（儿童信息专门处理规则链接）→ 监护人手机号 → 监护人收验证码 → 确认同意 → 注册完成。
- 交互：结果页告知监护人可随时撤回（撤回入口在登录页/帮助页“监护人服务”独立核验入口X16，设置提供同入口）。状态：验证失败可重发 3 次后转人工客服（帮助页）。

### A7 养宠标签引导（#+）
- 结构：2 步问题（养了什么/阶段），chip 多选。交互：**右上角「跳过」始终可见**，完成进入首页。

## B. 首页 Tab 与用品（L2/6 链）

### B1 首页（#7）
- 结构（自上而下）：**提醒条**（有待办时置顶：[疫苗·旺财·明天] → 点击进提醒；无提醒收起）→ **我的宠物卡**（头像横滑、体重快捷入口、「＋记录」主按钮）→ **逛好物频道**（分类横滑 chip + 评测 2 卡 + 我的最近收藏 3 件）→ **附近探索卡**（3 家场所 mini 列表 + 「查看地图」→ 探索 Tab）→ **资讯推荐**（8–12 篇卡片流）→ 页脚。
- 交互：宠物卡左滑切宠；「＋记录」→ 记录 Sheet（#32）一步直达（L2 生命链：首页 ≤1 次点击到记录）；频道 chip 点击进 #8/#9；刷新整页骨架。
- 状态：未登录 → 宠物区替换为「登录后开始记录」引导卡（资讯/用品可浏览）；无提醒 → 隐藏提醒条。

### B2 用品频道页（#8）
- 结构：分类横滑（7 类）→ 评测横滑卡 → 好物清单榜 → 网格商品卡（收藏心形角标）。
- 交互：点卡 → #10；分类 chip → #9。状态：空分类 → 空态。

### B3 分类商品列表（#9）
- 结构：顶部筛选条（适用宠物/生命阶段/价格区间 → Bottom Sheet）+ 排序（热度/上新）+ 卡片流分页。
- 状态：无结果 → 空态 + 「看看评测」引导。

### B4 商品详情（#10）
- 结构：图集（横滑+指示点）→ 标题/品牌/要点标签/参考价（「仅供参考」灰字）→ 参数表（折叠展开）→ 相关评测 → 所在清单 → 底部收藏按钮（主按钮宽条，**无购买按钮**）→ 已下架横幅。
- 交互：评测卡 → 文章详情；收藏即时 Toast。举报/纠错入口在更多菜单。

### B5 清单详情（#11）
- 结构：标题/作者/导语 → 有序商品卡（推荐理由一句）→ 底部点赞+收藏+分享。

## C. 资讯 Tab（L3 链）

### C1 Feed（#12）
- 结构：顶部分段 Tab（推荐 + 7 频道，滑块指示）+ 搜索图标 → 卡片流（封面/chip/标题/摘要/作者·时间），置顶卡大图样式。
- 交互：Tab 切换保留滚动位；触底加载；卡片 → 文章详情；下拉刷新。
- 状态：骨架屏；频道空 → 空态。

### C2 搜索页（#13）
- 结构：输入框（自动聚焦）+ 历史（可清）+ 热搜 → 结果分段（资讯/作者/商品），关键词**黄色高亮**。
- 状态：无结果 → 换词建议 + 推荐文章。

### C3 文章详情（#14）
- 结构：阅读进度细线（顶部）→ 标题/作者卡/时间·阅读时长 → 正文（720 等效排版、图片点开全屏预览）→ 疾病频道文末**免责声明固定条** → 相关商品卡（标注「相关推荐」）→ 底部互动条（点赞/收藏/评论数/分享）→ 相关文章 ×3。
- 交互：分享 → 分享面板（复制/微信/朋友圈/微博，深链带 UTM）；**举报在更多菜单**；未登录点赞/收藏 → 登录闸门 → 回跳保持位置；滚动 ≥200px 顶栏浮出作者+目录。
- 状态：已下架 → 降级页 + 推荐；图片失败占位。

### C4 评论区（#15）
- 结构：输入条置底（登录态）→ 评论列表（头像/名/时间/赞）→ 一层回复缩进。
- 交互：发送中…→ 成功上屏；**疑似违规评论仅自己可见**（灰条「评论审核中」）；长按操作（回复/举报/删除自己的）。

### C5–C8 关注/专题/作者主页/收藏（#16–19）
- 关注页：作者动态流 + 掉粉空态引导；专题页：导语 + 有序文章；作者主页：头像/简介/关注按钮（关注态变「已关注」）/文章列表；收藏分组：分组 Tab + 长按移动分组 + 左滑取消收藏。

## D. 探索 Tab（L5 链）

### D1 地图页（#20）
- 结结构：顶部搜索条 + 筛选按钮 + 城市定位标；地图占屏 65%，**底部卡片列表**（横滑，与地图选中态联动）；聚合点点开散开。
- 交互：**首次进入才申请定位**（用途说明）；拒绝 → 城市选择页（记忆）；筛选 → Bottom Sheet（类型 7 + 距离 5/10/20km + 评分/营业中/属性）应用后卡片列表与钉同步；点卡/钉 → #21；地图拖动更新范围 + 「刷新此区域」。
- 状态：地图加载失败 → 纯列表降级；稀疏区 → 「成为第一个贡献者」空态 + 运营提报入口。

### D2 场所详情（#21）
- 结构：头图相册 → 名称/类型/评分/营业状态 → 操作行（收藏·导航·拨号·**写评价**·纠错·举报）→ 信息组（地址/电话[登录可见完整]/时间/设施标签）→ 位置小图 → 评价列表（评分分布 + 评价卡）。
- 交互：导航 → 调起系统地图（弹选择器）计入转化；拨号 → 系统拨号；写评价 → #22；停业横幅置顶。

### D3 写评价（#22）
- 结构：三维评分（大星星，点选动效）→ 文字（占位引导「宠物友好度如何？」）→ 图片九宫格（+ 号 → 拍照/相册 Sheet，权限说明）→ 提示「发布即同意社区规范」→ 发布。
- 交互：字数计数；普通评价过滤后公开；注册未满7天或风险命中则仅本人待审，通过后才公开和计分 + Toast「感谢贡献」；同场所当日已评 → 防刷提示。
- 状态：图片上传进度条、失败重试。

### D4 纠错（#23）：类型单选 → 正确信息字段（按类型动态）→ 佐证图 → 提交 → 工单状态可在消息中心查看结果。

### D5–D7 路线（#24–26）
- 频道：路线卡（起终点/距离/耗时/难度 chip）+ 悬浮「发布路线」主按钮；详情：大图路线 + 途经说明 + 收藏/赞/分享/举报；发布：**地图选点模式**（点击加点、拖动调整、连线自动算距离）→ 表单（名称/耗时/难度/特色/照片）→ 草稿自动存 → 提交审核（状态见创作中心式进度提示）。

### D8–D9 活动与领养（#27–28）
- 频道：城市切换 + 类型 chip（集市/领养日/课程/**领养**子 Tab）+ 活动卡（日期大字徽章/地点/报名状态）。
- 详情：头图 → 标题 → 时间地点卡（「去这里」导航）→ 图文 → **底部主按钮「立即报名」** → 点击先弹**告知同意卡**（姓名+电话将提供给发布方）→ 同意 → 表单 → 提交成功（本人查询编号展示，站内消息通知，并提供“查看我的报名”；编号不用于核销）。
- 领养详情复用阅读组件但按钮为“联系发布者”，无报名按钮 + **风险提示条**（核验检疫证明/防诈骗/建议签协议）+ 无交易按钮；发现售卖 → 举报入口。

## E. 宠物管理（L2 核心）

### E1 宠物列表（#29）
- 结构：宠物大卡（头像/品种/年龄/最近体重）+ 「＋新建」；未完成草稿卡标「继续完善」。
- 交互：点卡进详情；左滑归档/删除（删除→二次确认→软删提示）。

### E2 建档向导（#30 · 4 步）
- 结构：顶部进度条 + 单列步进：①物种（三选一大卡）②昵称/品种(搜索)/性别/绝育/生日(日期滚轮)③照片(可跳过，相机/相册)④体重基线 → **完成页**：撒花插画 + 「设置第一个提醒」推荐卡（疫苗/驱虫）→ 设提醒（#34 预填）或先去详情。
- 交互：每步「上一步/下一步」；中途返回 → 弹「保存草稿？」；进度本地暂存（刷新不丢）。

### E3 宠物详情（#31 · 4 子 Tab）
- 结构：头图 + 名字/品种/年龄 + 快捷行（**记录**主按钮 / 曲线 / 摘要 / 更多[编辑/共享/归档/删除]）→ 分段子 Tab：
  - **时间线**：类型筛选 chip + 月分组条目（记录/提醒完成/里程碑），点条目看详情；
  - **健康记录**：6 类分组统计 + 记录列表 + 「＋记录」；
  - **提醒**：状态分组（待处理/已启用/已完成/已过期）+ 卡片（完成✓滑动操作）；
  - **档案资料**：字段表 + 编辑入口。
- 交互：「记录」→ #32 Sheet；「共享给家人」→ #38/#39（未建家庭先引导创建）；家庭成员视角：按BR-03逐动作判权；可管理无删除/转移/导出权，只读隐藏提交入口并说明权限。

### E4 记录表单（#32 · Sheet）
- 结构：类型选择（7 图标 chip，进入已选）→ 动态字段（按需求 B4 字段表）→ 日期默认今天 → 附件（可选）→ 保存。
- 交互：疫苗/驱虫填未来日期后选择关联现有计划或新建单次计划，保存成功展示实际下一期，避免重复创建；体重：数字键盘 + 单位切换(kg/斤) + **≥10% 变化弹二次确认卡**；发生日期>今天才报错；未来提醒须>当前时刻，用药结束可为未来且≥开始（BR-07）。平台保存成功 → Sheet 收起 + 时间线结果；仅体重事件更新曲线。离线保存显示待同步，不播放完成反馈。

### E5 体重曲线（#33）
- 结构：大图曲线（数据点<2 → 点列表）+ 趋势徽章（较 7 日前 ↑5% 高亮橙色）+ 数据点列表（点选 → 图上高亮 + 跳对应记录）+ 「＋记录体重」底按钮。
- 交互：横向滚动 + 双指缩放（区间切换周/月/全）；首次进入曲线**绘制动画**。

### E6 提醒中心（#34）
- 结构：提醒卡列表（宠物头像+类型+下次时间+状态）+ 悬浮新建；新建/编辑页：类型、周期（单次/每N天/每年）、时间(滚轮)、备注、**通知渠道说明**。
- 交互：到期提醒在首页提醒条与通知中心处理（完成→X01关联/新增记录和下期预览→平台确认成功→写完成历史）；跳过本次/暂停计划分别确认，同类批量须列出具体计划；创建成功 → 通知权限申请（若未给）。

### E7 健康摘要（#35 → #36）
- 生成页：所有者核验后勾选档案/有效过敏/当前用药/近期记录/提醒，近期可选30天/90天/全部；长期信息不受窗口过滤→ 生成（loading 动效）→ 摘要长图预览 → 保存相册/分享面板；**不含手机号等隐私**；预览页全屏（#36）双击缩放。

### E8 编辑档案（#37）：同向导字段的表单页 + 底部「归档此宠物」「删除档案」（删除 → 二次确认 → 说明软删 30 天）。

## F. 家庭共享（L9）

### F1 家庭页（#38）
- 结构：家庭头卡（名称/头像）→ 成员列表（头像+昵称+档位 chip+创建者徽章）→ 操作（邀请成员/移除/退出家庭/解散[创建者]）→ 宠物共享列表。

### F2 邀请（#39）：邀请码大图（7 天倒计时）+ 「复制链接」「分享」面板 + 「重置邀请码」；分享卡片深链跨端可开。

### F3 加入家庭（#40）：深链落地 → 告知卡（仅所选共享档案、健康记录、提醒和录入人对授权成员可见；私人收藏/草稿/报名不自动共享）→ 「确认加入」→ 落到共享宠物详情；**已在其他家庭 → 全屏提示先退出原家庭**（附退出入口）。

## G. 创作中心（L4）

### G1 主页（#41）：主按钮「新建」→ 文章/评测/好物清单类型选择→相应编辑器；三宫格入口：草稿箱（数字角标）/ 我的投稿（状态筛选）/ 创作数据；下方投稿列表（状态徽章）。

### G2 编辑器（#42）
- 结构：标题输入 → 封面（裁剪选图）→ 频道+标签选择 → 正文（富文本工具条：标题/加粗/列表/图片/链接，移动端简化排版能力）→ 底部「存草稿」「提交审核」。
- 交互：**自动保存（30s/离开触发）+ 顶部「已保存于 hh:mm」**；未保存离开拦截；提交前预览全屏。
- 状态：提交中锁按钮 → 成功返回列表（状态=待审核）。

### G3 投稿状态（#43）：状态时间线（提交/审核中/结果+时间）→ 驳回：意见卡（原文高亮问题区）+「修改重提」预填原稿；质量退修不计处罚；180天内3次人工确认违规驳回暂停7天，显示依据及申诉入口。

### G4 创作数据（#44）：单篇数据卡 + 7 日趋势折线（浏览为主）+ 互动明细列表。

## H. 我的 Tab 与设置（含合规能力）

### H1 我的（#45）
- 结构：头部（头像/昵称/养宠标签/编辑）→ 数据条（宠物 n·收藏 n·发布 n）→ 宫格（宠物/家庭/创作[无作品显示首次创作引导]/收藏/消息/活动中心）→ 列表组（帮助与客服、规则、设置）。
- 未登录 → 头部替换为登录引导大卡，宫格点击 → 登录闸门。

### H2 我的收藏（#46）：5 分组 Tab + 列表（同内容卡片）；左滑取消收藏、长按多选移动分组。

### H3 消息中心（#47）：5 分类 Tab（提醒/互动/审核结果/家庭/系统）+ 未读红点与「全部已读」；条目点击 → 深链（见架构 §3 路由表）；审核结果条目 → 投稿状态页。

### H4 设置主页（#48）与子页
- **资料编辑（#49）**：头像（裁剪）/昵称（24 字计数+敏感校验）/标签。
- **账号与安全**：换绑手机号（原号验证码 → 新号验证）、登录设备记录（异地登录提醒开关说明）。
- **隐私设置（#50）**：档案默认私有，所有者在X03主动选择共享宠物及成员档位、互动可见性、**撤回同意**（含监护人撤回入口）、清除搜索历史。
- **通知设置（#51）**：总开关（关 → 提示「将不再收到系统推送，站内待办仍可查看」确认）、分类开关、免打扰时段（时间区间选择器）。
- **数据导出（#52）**：说明（含 JSON 范围）→ 验证码核验 → 生成中进度 → 仅本人核验下载（24小时失效） + 「每次导出留痕」提示。
- **注销（#53）**：校验 → **失去内容清单**（档案/家庭/投稿）→ 阻断项检查（分别检查管理员职责、自有共享宠物、活动/报名和转移；提供转交/解散/解除共享/取消的实际入口，完成后解锁）→ 勾选确认 → 冷静期 15 天横幅（期间核验登录后显式确认撤销，不因误登录自动撤销）。

### H5 帮助与客服（#54）：搜索 + 分类 FAQ（手风琴）→ 未解决 → 联系表单（类型/留言/截图）→ 工单号查询；**处置申诉入口置顶卡**（有进行中处置时显示）。

### H6 规则页（#55 ×5）：统一阅读模板（更新日期+版本+锚点目录吸顶+正文）；投诉举报页含**在线举报表单**与邮箱公示。

### H7 封禁提示页（#56）：登录时全屏拦截 —— 原因/期限/依据条款 + **申诉按钮**（→ H5 申诉）+ 期满自动恢复提示。

### H8 错误页（#57）：断网插画 + 重试；内容不存在 → 推荐内容。
