## 2. 交互原则

- **通用**：登录闸门回跳不断链；写操作必有即时反馈（Toast/状态变化）；不可逆操作二次确认；每个列表定义空/载/错三态。
- **Web**：键盘可达（Tab 顺序 = 视觉顺序）、快捷键（`/` 聚焦搜索、`Esc` 关闭浮层）、大屏利用（双栏、表格、悬浮预览）。
- **移动**：单手可达、最少输入、手势跟手（见移动分册）。
- **管理端**：效率（批量、模板、快捷键 Enter 通过/Esc 关闭）、防错（高危二次确认、操作留痕提示）、可扫视（队列列表 + 等待时长高亮）。

## 3. 核心任务流程（L 链对齐，含状态与异常）

### L1 首次使用 → 建档 → 首条记录 → 设提醒 ⭐

```
落地(任意页) → [写操作/点击"开始记录"] → 登录闸门(半屏)
→ 登录页(协议勾选) → 验证码 → (新用户)年龄分支(≥14/<14监护人)
→ 回跳原位 → 建档向导(4步: 物种→基础→照片→体重, 顶部进度条)
→ 完成页 → 推荐设提醒(预填疫苗/驱虫) → 提醒创建页 → 完成 → 宠物详情
```
- 状态：向导中途退出 → 草稿保存，列表显示「继续完善」；登录后恢复原输入与确认页，报名/发布/加入不自动提交。
- 异常：验证码错误抖动清空；<14 流程失败 → 帮助/人工入口。
- 指标埋点：向导每步 PV、完成率、24h 内首条记录率。

### L2 日常留存 ⭐（生命链）

```
提醒触发(推送/站内) → 点开 → 宠物详情·提醒Tab(定位该提醒)
→ [记录完成] → X01关联已有记录/新增记录 + 下次计划预览 → 确认保存
→ 本次完成与记录同时成功 → 家人同步看到处理人 → 下一期待办
→ 体重事件可看曲线；资讯为可选后续动作
```
- 异常：断网保存 → 本地暂存标记「待同步」，联网按BR-04重新鉴权及去重，失权清理并提示；编辑冲突显式确认后覆盖。

### L3 内容消费与互动

```
首页/通知 → Feed(频道Tab,滚动位保留) → 文章详情(阅读进度)
→ 点赞/收藏/评论(未登录→闸门→回跳续做) → 分享(面板+深链) → 关注作者 → 回访
```
- 异常：内容下架 → 降级页+推荐；评论疑似违规 → 仅自己可见灰条。

### L4 UGC 生产与审核（含管理端）

```
[用户] 创作中心 → 编辑器(30s自动存) → 预览 → 提交 → 待审核
[管理] 审核工作台: 队列(等待时长>24h标红) → 详情预览+提交人历史
  → 通过(附言可选) → 发布 | 驳回(必填意见/模板快捷) → 作者收消息
  → 修改重提 → 复审 (质量退修不处罚；180天3次人工确认违规驳回才暂停7天，可申诉)
```
- 防重：标记「处理中」锁多人重复审核；批量操作二次确认。

### L5 探索导航

```
探索Tab(定位授权提示) → 地图⇄列表(联动) → 筛选Sheet(实时计数)
→ 场所详情 → 收藏/导航(调起地图,计入转化) → 导航结果；用户可另行写评价（普通过滤后公开，新号/风险先审）
→ 纠错/举报入口
```
- 异常：无定位 → 城市兜底（记忆）；地图失败 → 纯列表降级。

### L6 用品导购（无交易，修订版）

```
首页"逛好物"/用品频道 → 分类列表(筛选/热度排序) → 商品详情
→ 查参数/相关评测/所在清单 → 收藏(心形动效) → Toast
→ (评测)文章详情 → 商品卡 → 返回链路
```
- 明确：**无购物车/下单流**（方案 A）；转化指标 = 详情 PV、收藏率、导购点击。

### L9 家庭共享

```
宠物详情"共享给家人" → (无家庭)创建家庭 → 生成邀请(7天码) → 分享
[受邀人] 深链 → 登录/注册 → 加入家庭页(告知卡) → (已在其他家庭→先退出)
→ 确认加入 → 共享宠物详情 → 双方提醒/时间线同步
```

### G1 举报（全局）

```
对象页 更多→举报 → 面板(类型+说明+截图) → 提交 Toast("48h内通知")
→ 管理端举报队列 → 处理 → 结果通知举报人
```

## 4. 用户端 Web 文字低保真线框

### 4.1 首页
```
┌ 顶导: [Logo] 首页|宠物管理|资讯|探索|用品   🔔 👨‍👩‍👧 [头像▾] ─┐
├──────────────────────────────────────────────┤
│ Hero: 提醒卡(疫苗·明天) | 我的宠物横滑卡[＋记录]            │
│       附近探索mini列表(3)            资讯推荐大图+2小卡      │
├ 逛好物(分类chips | 评测卡×2 | 最近收藏×3) ──────────────────┤
│ 资讯流: [卡片][卡片][卡片] …          侧栏: 热门榜Top5/标签云 │
├ 页尾CTA(打开Web/手机打开) ──────────────── 页脚(4列+备案) ─────┤
```
- 桌面 1200 栅格，右侧栏 300；提醒卡仅在有待办时出现。

### 4.2 宠物详情
```
┌ 面包屑 首页>宠物管理>旺财                                    │
│ 头图+名/品种/年龄   [＋记录(主)] [曲线] [健康摘要] [更多▾]     │
│ 子Tab: 时间线 | 健康记录 | 提醒 | 档案资料                    │
│ ┌左70%内容区─────────────┐ ┌右30%摘要卡(体重趋势/下次提醒)┐  │
│ │ 时间线条目(类型筛选chip) │ │ 或 记录表单(点记录时右栏替换) │  │
│ └────────────────────────┘ └─────────────────────────────┘  │
```
- Web 优势：**左右双栏**——列表与表单/详情并置，免推入跳转（与移动 Sheet 对应）。

## 5. 管理端线框

### 5.1 审核工作台（核心页）
```
┌ 侧边栏(IA §7)                                    ┐
│ ┌ 队列Tab: 投稿|路线|活动|评价|评论|图片账号|举报|版权|申诉(角标数)
│ │ 筛选: 类型/提交人/等待时长(>24h红|>48h紫)/举报数   │
│ │ 列表行: [缩略]标题 提交人 提交时间 等待时长 [处理中锁] │
│ ├────────────┬──────────────────────────────────┤
│ │ 点击行 →    │ 右侧详情抽屉(60%宽):               │
│ │             │  内容预览(全文/大图) + 提交人历史摘要  │
│ │             │  操作区: ✅通过(附言) ❌驳回(意见模板) │
│ │             │        📌加急 🚫暂停投稿资格         │
│ │             │  底部: 审核记录时间线(留痕)           │
│ └────────────┴──────────────────────────────────┘
│ 批量: 全选→批量通过/驳回(二次确认弹窗)                 │
```
- 快捷键：↑↓ 选行、Enter 打开、A 通过、R 驳回、Esc 关闭抽屉（防错：A/R 需在详情页生效并二次确认弹层可选关闭）。

### 5.2 数据看板
```
顶部: 日期切换(日/周) + 告警条(积压>50/SLA超时)
四行卡片: 留存(DAU/WAU/建档/提醒完成) | 内容(发布/队列P50P90/UGC)
         | 探索(POI/评价/纠错时长) | 治理(举报时长/封禁)
下方: 模块负责人仅见有权限的卡片(RBAC #28)
```

### 5.3 通用后台交互
- 列表页：筛选条吸顶 + 列配置 + 导出(CSV)；表单页：分组卡片 + 底部吸底保存条；删除/封禁/批量 = 中央 Dialog 二次确认（输入确认词用于封禁）。

## 6. 跨端通用交互规范

| 项 | 规范 |
|----|------|
| 登录闸门 | 半屏/弹窗 → 登录后回原操作；点赞/收藏可续做，发布/报名/加入等恢复确认页 |
| 表单校验 | 失焦即时校验；错误=字段级红字；提交中禁用+spinner |
| 二次确认 | 不可逆/高危（删除、封禁、解散、注销）必弹；危险主按钮红字置右 |
| 三态 | 骨架屏(列表/详情)、空态(插画+主按钮)、错误态(重试)全页面覆盖 |
| 分页 | Web：数字页码+每页条数；移动/Feed：触底加载；管理端：页码+跳转 |
| 搜索 | 即时(≥2 字防抖 300ms) + 高亮 + 历史 + 空结果推荐 |
| 反馈 | 成功 Toast 2.5s；异步结果进消息中心；破坏性操作不只靠 Toast（需状态可见） |
| 键盘（Web/管理端） | `/` 搜索、`Esc` 关浮层、`Enter` 提交单行、快捷键面板 `?`（管理端） |
| 无障碍 | 全部交互键盘可达 + 焦点环；ARIA live 播报异步结果；见视觉设计 §7 |
| 深链 | 每个详情可独立打开；跨端打开落对应页（路由表见移动架构 §3，Web 同构） |
