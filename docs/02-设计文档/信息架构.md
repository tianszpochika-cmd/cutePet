# 设计文档 · 信息架构（IA）

> 状态：评审中（闭环修订完成） · 版本：v1.3 · 更新日期：2026-09-22
>
> 覆盖四端：用户端 Web、移动端、官网、管理端。基于当前闭环修订需求（含家庭共享、创作中心、路线/活动等全部一期入口）。

## 1. 设计原则

1. **场景优先**：导航按用户场景（管理/看/逛/找）划分，不按数据实体划分。
2. **四端同源**：账号、档案、内容数据同源；导航形态按端习惯适配（Web 顶部导航 / 移动底部 Tab / 管理端侧边栏）。
3. **游客可读**：未登录可浏览资讯、探索、商品；写操作（建档/互动/投稿）统一登录闸门 + 回跳。
4. **生命链优先**：L2 照护链（提醒→记录→家人同步→下次安排）在移动端必须一步可达。

- **首页**：聚合门户 — 提醒卡片 + 我的宠物 + 推荐资讯 + 附近探索 + 好物清单。
- **宠物管理**：宠物列表 → 宠物详情（Tab：时间线 / 健康记录 / 提醒 / 档案资料）。

## 3. 移动端全局导航（底部 4 Tab · ✅ 已决议：用品并入首页）

```

```

| Tab | 内容 | 说明 |
|-----|------|------|
| 首页 | 提醒条、我的宠物卡片（快速记录入口）、资讯推荐、附近探索、**用品频道（分类/评测/清单）** | L2 留存链枢纽 + 用品入口 |

## 9. 全局导航规则

- **登录闸门**：写操作触发登录 → 登录后回跳原页面原操作位（L1/L3 链不断）。
- **深链回跳**：分享卡片（公开文章/清单/路线/邀请；摘要为静态图片，仅附产品入口）跨端打开后落正确页。
- **角色入口**：管理端入口仅运营/管理员角色可见；C 端与管理端视觉隔离。
- **空状态**：每个列表页定义空状态与引导动作（如探索稀疏区「成为第一个贡献者」）。
- **异常降级**：无定位→城市选择；内容下架→降级页；断网→移动本地缓存提示。
