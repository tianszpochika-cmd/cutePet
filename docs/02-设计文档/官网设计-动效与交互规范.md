# 官网设计 · 动效与交互规范

> 状态：评审中 · 版本：v1.0 · 更新日期：2026-09-22
>
> 原则：**克制的可爱**——动效服务理解与愉悦，不阻塞内容（CLS≈0、可中断、可降级）。

## 1. 动效令牌

**缓动**

| 令牌 | 曲线 | 用途 |
|------|------|------|
| `--e-out` | `cubic-bezier(0.22, 1, 0.36, 1)` | 入场、抬升（主用） |
| `--e-in` | `cubic-bezier(0.55, 0, 1, 0.45)` | 退场 |
| `--e-standard` | `cubic-bezier(0.4, 0, 0.2, 1)` | 通用状态变化 |
| `--e-spring` | `cubic-bezier(0.34, 1.56, 0.64, 1)` | 弹性点缀（仅小元素，限次使用） |
| `--e-sway` | `ease-in-out` | 循环漂浮 |

**时长**

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--d-1` | 150ms | 按钮/hover 即时反馈 |
| `--d-2` | 250ms | 下拉、Tab、手风琴 |
| `--d-3` | 450ms | 卡片抬升、弹层 |
| `--d-4` | 600ms | 分节入场 |
| stagger | 80ms | 列表项级联间隔（每组最多 8 项） |

**黄金规则**：只动 `transform` / `opacity`（合成层）；禁止动画 `width/height/top/margin`（防重排）；单页动效总预算 ≤ 同屏 3 个循环动画。

## 2. 页面级动效

### 2.1 入场（每页 Hero）
1. 标题：**逐词/逐行** `translateY(16px) + opacity 0→1`，`--d-4 --e-out`，词间 stagger 60ms
2. 副标/CTA：延迟 200ms/320ms 同参数入场
3. 主视觉：`scale(0.96) + opacity` → 1，`--d-4`；随后内部装饰元素逐个 `--e-spring` 弹入（stagger 100ms）

### 2.2 分节滚动入场（IntersectionObserver, threshold 0.25）
- 容器：`translateY(24px) + opacity 0→1`，`--d-4 --e-out`
- 内部卡片级联 stagger 80ms（每组 ≤8，超出整组同时入场）
- **只触发一次**（入场后 unobserve）；同元素重复进入不重播

### 2.3 首页专属
- **信任条数字**：进入视口 count-up 0→目标值，1200ms `--e-out`，等宽数字防抖动
- **Hero 视差**：鼠标移动 → 装饰元素反向位移（分层系数 0.02–0.06，最大 8px），`raf` 节流；触屏禁用
- **主视觉漂浮**：装饰元素 `translateY ±8px` 循环，2.6–3.4s `--e-sway`（各元素周期错开），最多 3 个元素同时循环
- **Story 滑块**：切换 450ms `--e-out` 横移 + 指示条伸缩；支持拖拽跟手、释放回弹 `--e-spring`
- **口碑墙**：自动轮播 5s/张，hover 暂停；进出场 300ms 交叉淡化

### 2.4 产品页专属
- **Mockup 展示台**：常态 12° 倾斜 + 轻投影 → hover 回正 0° + `--sh-3`，450ms `--e-out`；3D 用 `rotate3d`，性能安全
- **步进时间轴**：滚动进度点亮——经过节点时序号徽章 `scale(0.8)→1.1→1` 弹入（`--e-spring` 300ms），连线用 `transform: scaleX` 生长
- **地图钉落下**（探索页）：钉从 `translateY(-24px)` 落下 + 底部阴影脉冲，stagger 70ms，循环每 4s 随机一个钉轻跳
- **提醒演示**（管理页）：手机 Mock 内通知条从顶部滑入 450ms → 停 1.5s → 淡出，4s 循环（仅此一个循环动画）
- **文章翻牌**（资讯页）：卡片 3D `rotateY` 翻转切换 600ms，背侧为另一篇推荐

### 2.5 页面转场（多页站）
- 离开：当前页内容 `opacity→0` 150ms `--e-in`（`beforeunload` 不阻塞）
- 到达：新页按 §2.1 入场（浏览器默认渲染 + 类切换实现，无路由强依赖）
- 顶栏进度条：页面加载时顶部 2px 主色细条 0→100%（不确定时用 60% 循环滑动）

## 3. 组件微交互

| 组件 | 触发 | 规格 |
|------|------|------|
| 主按钮 | hover / active | 上浮 2px + 彩色投影（150ms）/ 缩 0.97（80ms）；按下回弹用 `--e-spring` |
| 次按钮 | hover | 底色切 `--primary-soft` 150ms |
| 产品/文章卡 | hover | 整卡 `translateY(-4px)` + `--sh-1→--sh-2`（450ms）；封面内 `scale(1.04)`；模块描边渐显 |
| 卡内图标 | hover | 旋转 -6° 或轻跳一次（`--e-spring` 300ms，一次性不循环） |
| 导航下拉 | open | 面板 `opacity + translateY(8px)→0` 250ms；项级联 40ms |
| 吸顶导航 | scroll>64 | 背景 blur 与阴影 250ms 渐显/渐隐（`--e-standard`） |
| 移动抽屉 | open/close | 遮罩淡入 + 面板右侧滑入 300ms `--e-out`；关闭 250ms `--e-in`；打开时锁定滚动 |
| FAQ 手风琴 | toggle | 高度用 grid-template-rows `0fr→1fr` 过渡 250ms；图标旋转 45° 同步 |
| Tab 指示条 | 切换 | 滑块 `translateX + width` 250ms `--e-standard` |
| 二维码卡 | hover | 码 `scale(1.06)` + 虚线边框扫描线（1px 主色线 1.2s 线性循环扫过） |
| 登录引导弹层 | open | 遮罩 200ms 淡入 + 内容 `scale(0.95)→1` 250ms `--e-spring` |
| Toast | show | 顶部滑入 250ms；消失淡出 200ms |
| 阅读进度条 | scroll | 线宽 = 滚动进度，`transform: scaleX` raf 更新（无 transition，跟手） |
| 面包屑/链接 | hover | 下划线从左生长 150ms（`background-size` 技巧） |
| 表单校验 | error | 字段描边变红 + 错误字上移 6px 淡入 150ms；**不做整表抖动**（不礼貌） |
| 分享弹层 | hover 二维码 | 同二维码卡 |

## 4. 加载与媒体动效

- **骨架屏**：shimmer 从左到右 1.2s 线性循环；内容到达交叉淡化 200ms
- **图片**：`opacity 0→1` 300ms（decode 后挂类）；LCP 图片不做懒加载
- **视频位**（Campaign 模板）：占位图 + 播放按钮 hover 放大 1.05；点击原地展开（高度过渡 300ms）
- **步进/轮播**：自动播放间隔 ≥3s，hover/聚焦暂停，键盘 ←/→ 可控

## 5. 空态与反馈动效

- 空态插画：进入时轻浮动一次（`translateY ±4px` 单循环 800ms），不循环
- 成功反馈：按钮内图标变 ✓（200ms 形变）→ Toast
- 数字徽章（消息/榜单）：更新时 `scale 1→1.2→1` 弹一下（`--e-spring`）

## 6. 无障碍降级（强制）

```css
@media (prefers-reduced-motion: reduce) {
  /* 保留：≤100ms 的 opacity 变化 */
  /* 禁用：位移、缩放、旋转、视差、循环漂浮、count-up（直接显示终值） */
}
```
- 轮播/滑块停止自动播放，仅手动切换（仍保留 ARIA live 播报）
- 所有入场动画在无 JS 环境下内容默认可见（动画类由 JS 挂载，`no-js` 无隐藏态）

## 7. 性能预算与验收

- 动画帧率 ≥55fps（中端 Android Chrome 实测）；单页循环动画 ≤3
- CLS ≤0.05：动画元素预留空间，入场只用 transform/opacity
- LCP ≤2.5s（首屏大图为 LCP 候选，禁止对 LCP 图做入场动画依赖）
- 首屏 JS ≤150KB gzip（动效不引重型库：不使用 GSAP，用 CSS + WAAPI + IntersectionObserver）
- 验收清单：① reduced-motion 全过 ② 键盘过所有交互 ③ 飞书/真机三端（1200/768/375）走查动画无溢出
