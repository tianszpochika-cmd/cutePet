# 功能设计 · 宠物探索

> 状态：评审中（闭环修订完成） · 版本：v1.2 · 更新日期：2026-09-22

## 1. 地图与列表（D1/D2）

**主流程**
```
进入探索 → 获取定位
  ✅ 成功：以定位为中心加载附近 POI（默认范围 5km，可扩）
  ❌ 失败/拒绝：城市选择页 → 城市级列表
→ 地图 ⇄ 列表双视图（同一数据源，选中态联动）
→ 筛选（类型/距离/评分/营业中/友好属性）→ 结果更新
→ 点击 → 场所详情
```

**规则**
- POI 卡片：缩略图、名称、类型、距离、评分、营业状态。
- 列表分页；地图聚合点（密集时聚合显示数量，点开展开）。
- 排序：**综合分 = 0.6×距离归一 + 0.4×评分归一**（无评价按 3.5 均值）/ 距离 / 评分（已决议）。
- 城市切换持久化（下次进入沿用）。

## 2. 场所详情（D3/D4）

**页面结构**：头图相册 → 基础信息（地址/电话/营业时间/属性标签）→ 设施 → 用户评价（评分分布+列表）→ 地图位置 → 操作栏（收藏 / 导航 / 拨号 / 纠错 / 写评价）。

- **导航**：唤起系统地图应用（移动端）/ 展示路线页（Web）；点击计入转化埋点。
- **收藏**：幂等开关，进「我的收藏-场所」。
- 电话展示（已决议）：登录用户可见完整电话，游客脱敏显示（138****0000）。

## 3. 评价与纠错（D5 · UGC）

**写评价**
```
场所详情 → 写评价 → 三维评分（宠物友好度/环境/服务）+ 文字 + 图片(≤9)
→ 普通账号无风险且过滤通过 → 公开展示并计分
→ 新号/短文五星/重复图片/疑似任一命中 → 仅本人待审 → 审核通过再公开计分
```
- 防刷规则（一期）：同一账号对同一场所 1 天限 1 条；同一设备频次限制；新号未满7天、全三项五星且正文去空白少于10字、图片重复或疑似违规任一命中，仅本人待审，通过后公开计分（BR-05）。
- 评价可被举报；被处理的评价对他人隐藏。

**信息纠错**（状态机见总纲③）
- 表单：问题类型（地址/电话/营业时间/停业/属性）+ 正确信息 + 佐证照片（选填）。
- 提交 → 待处理 → 采纳（信息更新，贡献者消息中心通知）/ 驳回（附理由）。
- 同一 POI 相同纠错合并处理。

## 4. 遛宠路线（D6 · 先审后发）

**发布流程**
```
路线发布页 → 起点/终点（地图选点）→ 途经点打点连线 → 基础信息
（名称/距离(自动估算)/预计耗时/难度/特色/照片）→ 草稿 → 提交审核 → 通过 → 上线
```
- 一期采用**地图选点连线**的简化绘制（不支持真实轨迹上传，降低门槛；真实轨迹留二期）。
- 浏览：路线频道（城市/距离筛选）→ 详情（大图路线、途经说明、收藏/点赞/分享）。
- 骗子/危险路线举报 → 复审下架。

## 5. 本地活动与领养（D7）

“我的→活动中心”包含我的报名、我发布的和机构认证，所有登录用户可进入。普通活动：普通用户先审，认证机构/运营经安全检查直发；领养全部人工审核。

X09发布→审核/上线→单独同意并校验截止/名额/重复→查询凭证→X10我的报名→X11组织者名单/修改/取消→结束清理。姓名电话清理取提交90天和结束/取消后30天的较早者。组织者仅见自己活动，普通组织者不批量导出。

活动：未开放/报名中/已截止/进行中/已结束/已取消；报名：成功/本人取消/活动取消。重大修改先暂停报名，通过后通知全部有效报名者；取消立即执行通知。查询编号不承担门票或核销用途。

领养独立类型，动物资料/联系方式/风险提示/举报，无报名按钮。认证、名额并发、重复/取消后重报及清理按BR-05。

## 6. 数据自维护（治理联动）

- 评价/纠错/路线/活动产生的贡献通过消息通知贡献者；贡献展示（榜单/等级）**列二期**（已决议）。
- POI 状态：正常 / 停业（列表降权隐藏）；全部停业 POI 进入运营复核队列。

## 7. 异常汇总

| 场景 | 处理 |
|------|---|
| 无定位 | 城市兜底（记忆上次选择） |
| 稀疏地区无结果 | 「成为第一个贡献者」+ 提报入口 |
| POI 已停业 | 详情页横幅提示 + 仅历史评价可见 |
| 地图资源加载失败 | 降级为纯列表视图 |

## 8. 多端差异

- **移动端（主场景）**：定位实时、导航唤起、现场拍图评价、发布路线的选点操作。
- **Web**：大屏地图与列表、路线浏览、管理端视角的 POI 运营。
- 官网：活动精选展示（跳转用户端）。
