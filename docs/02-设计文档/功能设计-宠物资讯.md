# 功能设计 · 宠物资讯

> 状态：已定稿 · 需求追溯：C1–C7、C9 · 版本：v1.1 · 更新日期：2026-09-22

## 1. 内容消费（C1/C2/C6）

**首页 feed**
- 结构：置顶位 → 专题卡（运营配置）→ 推荐流（一期 = 编辑精选 + 热度排序，无个性化）。
- 流式分页加载；频道 Tab 切换保留各自滚动位置。

**频道与专题**
- 7 个固定频道（犬/猫/异宠/营养/疾病健康/训练行为/快讯）；快讯为短讯流形态。
- 专题 = 运营聚合页（标题+导语+有序文章列表），可被推荐位引用。
- 榜单 = 周期聚合（如本周热门），运营一键生成。

**搜索**
- 全局搜索框 → 结果页：文章 / 标签 / 作者 三类结果分区。
- 匹配标题 > 摘要 > 标签；空结果 → 热门推荐 + 换词建议。

## 2. 互动（C3/C4/C5）

**点赞/收藏/分享**
- 点赞、收藏为幂等开关；收藏默认进「默认分组」，可移动到自定义分组。
- 分享：生成卡片（标题+封面+链接），深链回跳到文章详情。

**评论**
- 结构：一级评论 + 一层回复（不递归）；支持点赞、举报、删除自己的评论。
- 流程：输入 → 敏感词即时过滤 → 通过即发；疑似违规 → 进入「仅自己可见待审」态（管理端复审）。
- 未登录评论 → 登录闸门回跳原评论位。
- 排序：时间序（默认）/ 点赞序。

**关注（C5）**
- 关注作者/话题 → 「关注」页聚合其新内容；关注数/粉丝数在作者主页展示。
- 被拉黑/封禁作者的内容处理：封禁作者内容从流中隐藏（治理联动）。

## 3. UGC 投稿（C7/C9 · L4 生产链 · 状态机见总纲①）

**创作中心结构**
```
创作中心
├── 写文章（编辑器：标题/正文/封面/频道/标签）
├── 草稿箱（自动保存 30s/离开触发；草稿仅本人可见）
├── 我的投稿（列表：状态徽标 + 驳回意见 + 「修改重提」）
└── 创作数据（每篇：浏览/点赞/评论/收藏；趋势图）
```

**投稿流程**
```
写文章 → 预览 → 提交审核
  → 进入待审核队列（管理端）
  → ✅ 通过：发布上线（作者可申请下架自己的文章）
  → ❌ 驳回：必附意见 → 作者修改 → 重提（次数不限；累计 **3 次**不过 → 暂停投稿资格 **7 天** + 转人工沟通——阈值已定稿）
```
- **先审后发**为唯一通道（一期无信用免审）。
- 作者主页（C9）：简介、文章列表（仅已发布）、关注按钮、创作数据仅作者自见。

**审核 SLA**：目标 24h 内处理；超时在管理端看板高亮（指标口径见管理端功能设计）。

## 4. 状态与字段

- 文章状态：草稿 / 待审核 / 审核中 / 已发布 / 已驳回 / 已下架（运营）/ 作者撤回。
- 每次审核记录：审核人、时间、动作、意见（全量留痕）。
- 已发布文章被下架：详情页降级为「内容已下架」+ 相关推荐；已收藏列表同步标记。

## 5. 异常汇总

| 场景 | 处理 |
|------|------|
| 编辑器崩溃/误退出 | 草稿本地+云端双存，重进提示恢复 |
| 重复提交 | 提交按钮幂等锁 |
| 详情 404/下架 | 降级页 + 推荐内容 |
| 敏感词命中 | 即时提示修改；发布后命中→下架进复审 |

## 6. 多端差异

- 移动端：投稿提供适配触屏的编辑器（富文本能力可简化，支持图片插入）；push 承载「审核结果」通知。
- Web：完整编辑器、创作数据大屏图表。
- 官网：仅展示精选文章（只读）。
