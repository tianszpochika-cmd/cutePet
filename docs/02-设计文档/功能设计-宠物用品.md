# 功能设计 · 宠物用品（方案 A · 内容导购）

> 状态：已定稿 · 需求追溯：E1–E3 · 版本：v1.1 · 更新日期：2026-09-22

## 1. 分类与商品库（E1）

**分类树（一级）**：主粮 / 零食 / 玩具 / 清洁护理 / 医疗保健 / 出行用品 / 服饰窝垫。

**商品实体字段**
| 字段 | 说明 |
|------|------|
| 名称、品牌 | 必填 |
| 分类（一级/二级） | 必填 |
| 规格/口味 | 多规格展示 |
| 适用标签 | 宠物类型(犬/猫/异宠)、生命阶段(幼/成/老)、特性(无谷/处方等) |
| 参考价格区间 | 展示用，标注「仅供参考」 |
| 要点标签 | ≤5 个短标签 |
| 封面/相册 | 运营维护 |
| 状态 | 上架/下架 |

**浏览与筛选**
- 分类页：卡片列表 + 筛选（适用宠物/生命阶段/价格区间）+ 排序（热度/上新；**热度 = 近 30 天 浏览量 + 收藏×3，每日重算**——口径已定稿）。
- 搜索：名称/品牌匹配，空结果引导相关评测。

## 2. 商品详情页

```
[头图+名称+品牌+要点标签+参考价]
[参数表（规格/适用/成分要点）]
[相关评测 ←→ 绑定文章列表]
[所在清单（运营/作者清单）]
[收藏按钮] （无购买按钮、无购物车——方案A约束）
[免责提示：价格仅供参考，信息以实物为准]
```

- 下架商品：详情保留（评测内旧链接可达）但顶部横幅「已下架」，收藏列表标记。

## 3. 评测与清单（E2 · 导购核心）

**双向关联**
- 评测文章 = 资讯文章 + `关联商品` 字段 → 文内商品卡（点击进详情）。
- 商品详情 → 反向聚合「相关评测」。
- 关联为运营/作者在编辑器中选择商品建立；商品删除 → 文内卡降级为纯文本（保留文章可读）。

**清单**
- 结构：标题+导语+有序商品卡列表（每卡可带一句推荐理由）+ 作者（运营/作者）。
- 类型：运营官方清单 / 用户作者清单。
- 流程：作者在创作中心可创建清单（复用投稿审核状态机①）；运营清单直接发布。
- 清单页：点赞、收藏、分享；清单与文章互相引用（清单型文章）。

## 4. 收藏与我的清单（E3）

- 商品收藏：详情页/卡片上的收藏开关 → 「我的收藏-商品」。
- 我的收藏内支持简单分组（复用资讯收藏的分组能力，同一套收藏组件）。
- 收藏数据计入首页「好物」回访入口（首页展示最近收藏 3 件）。

## 5. 运营维护流程（管理端联动）

```
商品录入（字段见§1）→ 审核内部校验 → 上架 → 进入分类/搜索
→ 关联评测/清单运营 → 数据查看（浏览/收藏）→ 更新或下架
```
- 商品与评测的一致性巡检：下架商品被引用时的降级已定义，无需阻断下架。

## 6. 异常汇总

| 场景 | 处理 |
|------|------|
| 搜索无结果 | 热门分类 + 相关评测推荐 |
| 评测关联商品被删 | 商品卡降级纯文本 |
| 参考价过期 | 不阻断（免责声明覆盖）；**每月**巡检一次（看板提醒，已定稿） |

## 7. 多端差异

- 移动端：卡片流浏览、收藏一键；详情页适配小屏参数表（折叠展开）。
- Web：详情页大屏陈列优化；**一期不做多商品参数对比工具**，对比功能列二期（已决议）。
- 管理端：商品库 CRUD（见管理端功能设计）。
