# 官网设计 · UI 视觉规范

> 状态：评审中 · 版本：v1.0 · 更新日期：2026-09-22
>
> 官网视觉体系（设计令牌 + 组件）。品牌关键词沿用 `视觉设计.md`：**可爱 / 温暖 / 可信**。
> 本文是全项目第一套落地视觉系统，后续 `视觉设计.md` 定稿时吸收并扩展到四端。

## 1. 色彩令牌

**品牌色**

| 令牌 | 值 | 用途 |
|------|-----|------|
| `--primary` | `#FF7A2F` 暖橘 | 主按钮、链接、品牌色 |
| `--primary-hover` | `#F26A1B` | 悬停加深 |
| `--primary-soft` | `#FFF1E8` | 主色浅底、tag |
| `--ink` | `#2B2118` 深可可 | 标题与正文 |
| `--ink-2` | `#7A6E63` | 次级文字、说明 |
| `--line` | `#F0E6DC` | 描边、分割线 |
| `--bg` | `#FFF9F3` 奶油 | 页面底色（温暖感） |
| `--surface` | `#FFFFFF` | 卡片、浮层 |

**模块色**（页面/图标标识，见页面架构 §3）
管理 `#FF7A2F` · 资讯 `#FF5C7A` · 探索 `#2FBF71` · 用品 `#4D8DFF` · 家庭 `#9B8CFF`

**语义色**：成功 `#22C55E` · 警告 `#F59E0B` · 错误 `#EF4444` · 信息 `#4D8DFF`

**规则**：正文对比度 ≥ WCAG AA（4.5:1）；大面积底色只用奶油/白；模块色只用于所属页面局部，不混用。

## 2. 字体与字阶

- 字体栈：`"PingFang SC", "HarmonyOS Sans SC", "MiSans", "Microsoft YaHei", system-ui, sans-serif`（系统字，零版权风险）
- 数字/英文强调可用 `tabular-nums`；不引入付费字体。

| 层级 | 桌面 | 移动 | 行高 | 用途 |
|------|------|------|------|------|
| Display | 60/700 | 36/700 | 1.15 | 首页 Hero |
| H1 | 44/700 | 30/700 | 1.25 | 页面 H1 |
| H2 | 32/700 | 24/700 | 1.3 | 分节标题 |
| H3 | 22/600 | 19/600 | 1.4 | 卡片标题 |
| Body-L | 18/400 | 17/400 | 1.75 | 导语 |
| Body | 16/400 | 15/400 | 1.7 | 正文 |
| Small | 14/400 | 13/400 | 1.6 | 说明、脚注 |
| Eyebrow | 13/600 + 字距 0.08em | 同 | 1.4 | 分节小标签（模块色） |

**标题风格**：圆润感靠字重与字距（标题 letter-spacing -0.01em），不做描边/渐变文字（可信感优先）。

## 3. 间距 / 圆角 / 阴影

- **间距**（4 基数）：4 / 8 / 12 / 16 / 24 / 32 / 48 / 64 / 96 / 128
- **栅格**：内容宽 1200px；正文窄栏 720px；页边距 24（移动 16）；12 列栅格，卡片区 gap 24
- **断点**：`≥1200` 桌面 / `768–1199` 平板（栅格 8 列）/ `<768` 移动（4 列，导航收抽屉）
- **圆角**：`--r-s 8`（按钮/输入）· `--r-m 12`（小卡）· `--r-l 20`（大卡/弹层）· `--r-xl 28`（Hero 面板）· `--r-full 999`（chip/胶囊按钮）
- **阴影**：
  - `--sh-1`：`0 2px 8px rgba(43,33,24,.06)` 卡片常态
  - `--sh-2`：`0 12px 32px rgba(43,33,24,.10)` 悬停/浮层
  - `--sh-3`：`0 24px 64px rgba(43,33,24,.14)` 弹窗/吸顶
  - 彩色投影：主色 8% 透明度用于主按钮发光 hover

## 4. 组件规格

### 4.1 按钮
| 型 | 规格 |
|----|------|
| 主按钮 | 橘底白字，高 48（移动 44），padding 0 24，`--r-full` 胶囊；hover 上浮 2px + 彩色投影；active 缩 0.97 |
| 次按钮 | 白底橘字 + 1.5px 橘描边；hover 变 `--primary-soft` 底 |
| 幽灵按钮 | 透明底 + 灰描边，用于次要操作 |
| 图标按钮 | 40×40，`--r-m`，hover 灰底 |
| 禁用 | 40% 透明度 + not-allowed |

### 4.2 导航
- 高 64，滚动后 `backdrop-filter: blur(12px)` + `rgba(255,255,255,.8)` 底 + `--sh-3`
- 下拉面板：白底 `--r-l`，项高 40，当前项 `--primary-soft` 底
- 移动抽屉：右侧全高 80% 宽面板，链接 20/600，底部固定双 CTA

### 4.3 卡片
- 文章卡：白底 `--r-l`，封面 16:9 上圆角，内容 padding 20；hover `--sh-2` + 上浮 4px + 封面 scale 1.04
- 产品大卡：模块色 4% 底 + 左文右图；hover 描边 1.5px 模块色 + 图形微动
- 步骤卡：序号圆形徽章（模块色底白字 32×32）
- 楼层标题组件：Eyebrow（模块色）+ H2 + 一行副标（居中或左对齐二选一全站统一左对齐）

### 4.4 表单
- 输入高 44，`--r-s`，边 `--line`；focus 橘描边 1.5px + `--primary-soft` 外圈
- 错误：红描边 + 字段下 12px 红字（即时校验）
- 标签上置 14/600；提交按钮主按钮全宽（移动）

### 4.5 导航性组件
- 面包屑：14px `--ink-2`，分隔 `/`，末项当前页加粗
- Tab：文字 Tab + 滑块指示条（模块色，宽 = 文字宽）
- 手风琴 FAQ：行高 56，`+ / −` 图标旋转 45° 切换，内容高度过渡
- 二维码卡：白底 `--r-l` + 1px 虚线边，内嵌码，hover 放大 1.06 + 扫描线动画（见动效规范）
- 页脚：`--ink` 深底白字（或奶油底深字二选一 → **定稿：深可可底 `#2B2118` 白字**，增强可信收尾），4 列链接 + 条款行 + 备案号（备案号链工信部）

### 4.6 反馈
- Toast：顶部居中，深底白字 `--r-full`，3s 自动消失
- 弹层（分享/登录引导）：遮罩 `rgba(43,33,24,.45)`，内容 `--r-xl` + `--sh-3`
- 骨架屏：奶油→白 1.2s 循环 shimmer

## 5. 图像与插画风格

- 插画：圆润扁平 + 轻渐变，宠物 IP 圆头身比 1:1.5；爪印/骨头/定位针为装饰元素库
- 图标：2px 圆头线性图标（统一 24 网格），模块页图标用模块色
- 摄影/截图：产品 Mockup 统一 12° 倾斜展示台 + 柔投影；文章封面用插画或授权图（**UGC 图禁用官网**）
- 空态：宠物主题插画（迷路/打盹/好奇）全站统一画风

## 6. 响应式规则

| 元素 | 桌面 | 平板 | 移动 |
|------|------|------|------|
| 导航 | 全链接+双 CTA | 收起次要链接 | 汉堡抽屉 |
| Hero | 左右双栏 | 双栏缩比 | 单列（插画下置） |
| 卡片栅格 | 3–4 列 | 2 列 | 1–2 列 |
| 文章正文 | 720px 居中 | 同 | 全宽 -32 |
| 法律页 | 正文+左侧锚点 | 锚点收顶部 | 锚点折叠为"目录"按钮 |

## 7. 无障碍（强制）

- 键盘可达：所有交互元素可 Tab 聚焦 + 可见 focus 环（2px 橘描边 + 2px 偏移）
- 语义化：每页唯一 H1；landmark（header/nav/main/footer）；跳到主内容链接
- 图片 alt 必填；装饰图 `aria-hidden`
- 触控目标 ≥44×44；正文对比度 AA；支持 200% 缩放不破版
- `prefers-reduced-motion` 降级见动效规范 §6
