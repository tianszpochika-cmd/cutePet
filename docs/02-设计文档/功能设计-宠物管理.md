# 功能设计 · 宠物管理

> 状态：已定稿 · 需求追溯：B1–B6 · 版本：v1.1 · 更新日期：2026-09-22

## 1. 建档向导（B1 · L1 激活链关键）

```
新建宠物 → ①物种(犬/猫/异宠) → ②基础信息(昵称/品种/性别/绝育/生日)
         → ③照片(可跳过) → ④体重基线 → 完成 → 落到宠物详情页
         → 完成引导卡：「设置第一个提醒」（疫苗/驱虫推荐）
```
- 全程可返回上一步；中途退出保存为未完成草稿，列表显示「继续完善」。
- 步骤④后自动创建一条初始时间线事件「宠物档案创建」。
- **转化指标**：向导完成率、完成建档后 24h 内首条记录率。

## 2. 记录流程（B3/B4）

```
入口（宠物详情「记录」按钮 / 首页快速记录）
  → 选择记录类型（体重 | 疫苗 | 驱虫 | 体检 | 就医 | 用药 | 过敏）
  → 表单填写（各类型字段见下） → 保存
  → 时间线新增条目 + 曲线/健康视图更新 + Toast
```

| 类型 | 必填 | 选填 |
|------|------|------|
| 体重 | 数值、日期 | 备注、照片 |
| 疫苗 | 疫苗名称、接种日期 | 机构、下次提醒日期、照片 |
| 驱虫 | 类型(体内/体外)、日期 | 产品、下次提醒日期 |
| 体检 | 日期、结果摘要 | 机构、报告照片 |
| 就医 | 日期、原因 | 医院、医生、费用、附件 |
| 用药 | 药名、起止日期 | 剂量、医嘱 |
| 过敏 | 过敏原、反应 | 严重程度 |

- **联动规则**：填写疫苗/驱虫且给出「下次日期」→ 自动生成 B5 周期提醒（可修改/关闭）。
- **校验**：日期不得晚于今天；体重合理区间提示（0.1–200kg，超出需二次确认）。
- **多端冲突**：同记录以最后保存为准，覆盖前提示差异（一期简化为后写覆盖）。

## 3. 时间线（B2）

- 聚合事件源：体重、六类健康记录、提醒完成、里程碑（生日/到家纪念日）、档案变更。
- 筛选维度：全部 / 健康 / 体重 / 提醒 / 里程碑。
- 分页加载（按月分组）；单条可查看大图/详情（一期不支持编辑历史事件的复杂版本，仅支持编辑自己录入的条目）。

## 4. 体重曲线（B3）

- X=时间，Y=体重；展示均值、区间、趋势箭头（较 7 日前 ↑/↓/→，变化 **≥5%** 高亮提示——阈值已定稿）。
- 数据点 < 2 时只展示点列表，不画曲线。
- 曲线上可点击数据点跳转对应记录。

## 5. 提醒中心（B5 ⭐ 状态机见总纲②）

**字段**：宠物、类型（预设6类+自定义）、周期规则（单次/每N天/每年）、下次触发时间、状态、通知渠道（站内+移动端推送）、备注。

**流程**：
- 创建：宠物详情 → 提醒 Tab → 新建；或健康记录联动生成（预填可改）。
- 触发：到期 → 消息中心通知 + 移动端推送；未处理 **3 天**后标记已过期并二次提醒一次（已定稿）。
- 处理：完成（记录到时间线）/ 关闭（单次关闭 or 同类全部关闭）。
- 家庭联动：提醒归属宠物 → 家庭共享成员同步收到（权限=可管理成员可处理，只读成员仅可见）。

**边界**：推送失败→站内兜底+联网补推；一期统一按**北京时间**触发（已决议）。

## 6. 健康摘要分享（B6）

```
宠物详情 → 「健康摘要」→ 生成页（勾选模块：档案/近30天记录/提醒计划）
        → 生成图片卡片（含宠物名、核心数据、生成时间、平台标识）
        → 保存 / 系统分享
```
- 摘要为**静态快照**（不含实时数据）；不含主人手机号等隐私字段。
- 未完成建档（缺生日/品种）仍可生成，缺失项不展示。

## 7. 异常汇总

| 场景 | 处理 |
|------|------|
| 未登录建档 | 登录闸门 → 回跳向导进度 |
| 归档宠物 | 列表隐藏、历史保留、提醒批量关闭（确认后） |
| 删除宠物 | 二次确认 → 关联记录/提醒进入清理流程 |
| 无记录空态 | 引导「记录第一条体重」按钮 |

## 8. 多端差异

- 移动端：快速记录为一级能力（首页卡片直达）；提醒走系统推送；曲线小屏改为可横向滚动。
- Web：健康摘要可打印；批量录入场景（多宠家庭）优化列表切换。
- 管理端：不涉及（仅治理层可处理相关举报）。
