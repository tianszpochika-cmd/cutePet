# 功能设计 · 宠物管理

> 状态：评审中（闭环修订完成） · 版本：v1.2 · 更新日期：2026-09-22

## 1. 建档向导（B1 · L1 激活链关键）

```
新建宠物 → ①物种(犬/猫/异宠) → ②基础信息(昵称/品种/性别/绝育/生日)
         → ③照片(可跳过) → ④体重基线 → 完成 → 落到宠物详情页
         → 完成引导卡：「设置第一个提醒」（疫苗/驱虫推荐）
```
- 全程可返回上一步；中途退出保存为未完成草稿，列表显示「继续完善」。
- 步骤④后自动创建一条初始时间线事件「宠物档案创建」。
- **转化指标**：向导完成率、完成建档后 24h 内首条记录率。

## 2. 记录流程（B3/B4）

```
入口（宠物详情「记录」按钮 / 首页快速记录）
  → 选择记录类型（体重 | 疫苗 | 驱虫 | 体检 | 就医 | 用药 | 过敏）
  → 表单填写（各类型字段见下） → 保存
  → 时间线新增条目 + 曲线/健康视图更新 + Toast
```

| 类型 | 必填 | 选填 |
|------|------|------|
| 体重 | 数值、日期 | 备注、照片 |
| 疫苗 | 疫苗名称、接种日期或日期不详标记 | 机构、下次提醒日期、照片 |
| 驱虫 | 类型(体内/体外)、日期或日期不详标记 | 产品、下次提醒日期 |
| 体检 | 日期或日期不详标记、结果摘要 | 机构、报告照片 |
| 就医 | 日期或日期不详标记、原因 | 医院、医生、费用、附件 |
| 用药 | 药名、实际开始日期 | 结束日期（可为未来或持续中不填）、剂量、医嘱 |
| 过敏 | 过敏原、反应 | 严重程度 |

- **联动规则**：填写疫苗/驱虫且给出「下次日期」→ 无已有匹配计划时生成单次计划，有计划时选择关联或调整；周期由用户确认（BR-02）。
- **校验**：已发生事件日期不晚于今天；未来提醒须晚于当前时刻，用药结束可为未来且不早于开始（BR-07）；体重合理区间提示（0.1–200kg，超出需二次确认）。
- **多端冲突**：同记录冲突先展示差异，用户确认后才覆盖；离线新增按草稿编号去重，不静默覆盖（BR-04）。

## 3. 时间线（B2）

- 聚合事件源：体重、六类健康记录、提醒完成、里程碑（生日/到家纪念日）、档案变更。
- 筛选维度：全部 / 健康 / 体重 / 提醒 / 里程碑。
- 分页加载（按月分组）；单条可查看大图/详情（一期不支持编辑历史事件的复杂版本，所有者可更正任意条目，可管理成员仅更正自己条目；均留痕且需当前权限）。

## 4. 体重曲线（B3）

- X=时间，Y=体重；展示均值、区间、趋势箭头（较 7 日前 ↑/↓/→，变化 **≥5%** 高亮提示——阈值已定稿）。
- 数据点 < 2 时只展示点列表，不画曲线。
- 曲线上可点击数据点跳转对应记录。

## 5. 提醒中心（B5 ⭐ 状态机见总纲②）

计划页展示周期、排期基准、状态和下一期；待办页展示到期时间、处理人及关联记录。详细状态、提前/延期/跳过/恢复、并发与重试按BR-02。

完成健康类待办须新增或关联记录，平台确认保存与完成同时成功，另一家人重复处理返回原结果。三天未处理变逾期，不堆积多个待办；X02查看计划/历史，X01确认记录与下一期。

家庭接收者按BR-03及各自偏好；推送失败保留站内状态，重试前检查有效性，无可用通道显示仅站内提醒。

## 6. 健康摘要分享（B6）

```
宠物详情 → 「健康摘要」→ 生成页（所有者核验；模块为档案/有效过敏/当前用药/近30或90天或全部记录/提醒计划）
        → 生成图片卡片（含宠物名、核心数据、生成时间、平台标识）
        → 保存 / 系统分享
```
- 摘要为**静态快照**（不含实时数据）；不含主人手机号等隐私字段。
- 未完成建档（缺生日/品种）仍可生成，缺失项明确标记未提供，不生成虚假数据。

## 7. 异常汇总

| 场景 | 处理 |
|------|------|
| 未登录建档 | 登录闸门 → 回跳向导进度 |
| 归档宠物 | 移入归档列表、历史保留、解除共享、暂停计划并取消未终结待办（确认后） |
| 删除宠物 | 二次确认 → 关联记录/提醒进入清理流程 |
| 无记录空态 | 引导「记录第一条体重」按钮 |

## 8. 多端差异

- 移动端：快速记录为一级能力（首页卡片直达）；提醒按已验证授权通道触达，不支持时明确仅站内；曲线小屏改为可横向滚动。
- Web：健康摘要可打印；批量录入场景（多宠家庭）优化列表切换。
- 管理端：不涉及（仅治理层可处理相关举报）。
