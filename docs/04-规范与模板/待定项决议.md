# 待定项决议（2026-09-22 · 设计评审）

> 状态：已定稿 · 版本：v1.0
>
> 2026-09-22 设计评审中，项目负责人确认四项决策，并授权 Agent 决定全部产品/设计级「待定」细项。
> 本文为决议总账；各文档内对应位置已同步回填。**外部依赖（法务文案、技术选型、人工调研）不在此列。**

## 一、四项评审决策

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 移动端导航 | **4-Tab**：首页 / 资讯 / 探索 / 我的，**用品并入首页频道** |
| 2 | 家庭限制 | **一人同时仅可属于一个家庭**（加入前须退出原家庭） |
| 3 | RBAC 粒度 | **细粒度权限点制**（32 个权限点 + 预置 6 角色 + 支持自定义角色） |
| 4 | 「待定」细项 | 由 Agent 全部决议，逐项如下 |

## 二、细项决议清单

### 账号与家庭

| 项 | 决议 |
|----|------|
| 第三方登录渠道 | 一期 = 手机号验证码 + **微信登录**；其他渠道二期 |
| 注销冷静期 | **15 天**，期内可撤销；期满数据删除/匿名化（UGC 默认匿名化保留） |
| 邀请码 | 有效期 **7 天**、不限使用次数，创建者可随时失效重置 |
| 一人多家庭 | **禁止**，一期限一个家庭 |
| 异地/新设备登录 | **一期做**：消息中心 + 推送安全提醒 |
| 账号合并 | 仅同手机号可合并；不同手机号不合并并提示换号登录 |
| 数据导出格式 | 一期提供 **JSON** 文件（资料 + 宠物档案 + 健康记录），导出留痕 |
| 未成年人 | **2026-09-22 复议改定：方案甲** — 注册年龄分支，<14 岁走监护人同意流程（监护人验证+儿童信息专门规则）；**青少年模式一期不做**（负责人决策，风险已记入 PRD §8，复评节点：上线前/下载量过万前） |

### 宠物管理

| 项 | 决议 |
|----|------|
| 体重单次波动 | 较上一条记录变化 **≥10%** → 弹二次确认 |
| 曲线高亮阈值 | 较 7 日前变化 **≥5%** 高亮提示 |
| 提醒过期 | 到期未处理 **3 天**标记过期并二次提醒一次 |
| 提醒时区 | 一期统一按**北京时间**触发 |
| 多端编辑冲突 | **后写覆盖**（覆盖前提示差异），一期简化 |
| 档案删除保留 | **软删 30 天**可恢复，期满物理删除；治理强制清除即时生效 |

### 宠物资讯

| 项 | 决议 |
|----|------|
| 驳回阈值 | 累计 **3 次**驳回不过 → 暂停投稿资格 **7 天** + 转人工沟通 |
| 审核 SLA | **24h** 内处理；超 24h 队列标红，超 48h 升级通知主管 |
| UGC 授权 | 产品侧：投稿即授权平台展示与推广（条款文案 = 法务外部依赖） |
| 个性化推荐 | 一期**不做**，feed = 编辑精选 + 热度排序 |

### 宠物探索

| 项 | 决议 |
|----|------|
| 防刷细则 | 同账号同场所 **1 天 1 条**；同设备 1 天 ≤5 条；图片重复检测；全 5 分且正文 <10 字 → 进复审 |
| 评分聚合 | 展示全量有效评价均值；被隐藏/举报成立的不计；新账号（注册 <7 天）评价先审后计入 |
| 列表排序 | 综合分 = **0.6×距离归一 + 0.4×评分归一**（无评价按 3.5 均值），另提供距离/评分单排序 |
| 电话展示 | 登录用户可见完整电话（游客脱敏） |
| 活动报名 | **站内表单**（姓名+电话），直接提交成功 + 通知发布方，**无需审核** |
| 活动发布权限 | 运营/认证机构直发；普通用户提交 → 审核 |
| 路线绘制 | 一期**地图选点连线**（不支持真实轨迹，真实轨迹二期） |
| 贡献展示 | **二期**，一期仅消息通知 |

### 宠物用品

| 项 | 决议 |
|----|------|
| 外链跳转 | 一期**不提供购买外链**，纯内容导购；二期评估外链与合规 |
| 参数对比工具 | 一期**不做**，详情页仅陈列；对比列二期 |
| 热度排序口径 | 近 30 天 **浏览量 + 收藏×3**（每日重算） |
| 参考价巡检 | **每月**巡检一次（看板提醒） |
| 商品批量导入 | 一期支持 **CSV 批量导入** |

### 管理端

| 项 | 决议 |
|----|------|
| RBAC | 32 权限点、预置 6 角色、可自定义角色（见功能设计-管理端 §6） |
| 审计日志 | **记录 IP** + 操作者/时间/对象/动作/前后值 |
| 移动端管理兜底 | **不做**；非桌面浏览器明确提示「请在电脑端使用」 |

### 数据口径（数据设计）

| 项 | 决议 |
|----|------|
| 体重曲线数据点 | 时间戳 + 数值 + 单位（存储统一 kg，展示可换算斤） |
| 探索「附近」 | 直线距离，默认半径 **5km**，可切换 10/20km |
| 资讯推荐依据 | 一期无个性化：运营精选置顶 + 近 7 天互动热度排序 |

### 非功能与多端

| 项 | 决议 |
|----|------|
| 性能 | 首屏 ≤3s（4G）、常用接口 P95 ≤1s、可用性 ≥99.5% |
| 兼容 | Web：Chrome/Edge/Safari/Firefox 近 2 大版本；移动：Android 10+ / iOS 15+ 主流机型 |
| 离线容错 | 一期支持体重/健康记录**本地暂存→联网自动同步** |
| 移动端形态 | App/H5/小程序 —— 属**阶段二技术选型**（外部依赖，非产品待定） |
