# 验收走查清单（L1–L9）

> 状态：v1.0 · 2026-09-22 · 任务 T12.4（**走查执行与签字归本地/负责人阶段**）
> 口径：每层 =「入口可达 → 字段校验 → 提交防重 → 成功结果 → 失败保留/清理 → 返回原任务 → 权限变更后拒绝 → 跨端一致」（闭环文档 §4 交互验收方法）
> 配套：E2E 用例库 `scripts/quality/e2eCases.ts`（28 条）· [手动测试矩阵](../06-测试用例/手动测试矩阵.md) · [合规自查表](../06-测试用例/合规自查表.md)

## 使用说明

- 每层列出「必过项」；逐项 ☐ → ☑，任一必过项失败 → 缺陷入池（P0/P1 阻断本层签字）。
- 跨端项：web 与 mobile 各走一遍（同契约应一致）；site/admin 按层内标注。
- 证据：截图/日志归 E 层；L 层断言已由逻辑测试覆盖，走查不重复执行纯函数分支。

## L1 登录闸门

- [ ] 手机号+验证码登录成功；协议双勾未勾被拦（默认不勾选）
- [ ] 方案甲：<14 岁进入监护人同意，未同意无法进入私有功能；微信登录同样被拦（U83）
- [ ] 深链回跳：登录后回原目标而非首页；外部/协议相对目标被拒（U93 白名单）
- [ ] 移动 H5 同链路可用；受限游客（未同意隐私）不加载分析/定位

## L2 生命链核心

- [ ] 4 步建档逐步校验；建完可在详情看到四 Tab
- [ ] 7 类记录字段与校验（用药起止/未来事件拒/疫苗驱虫自动排期）
- [ ] 曲线：数据点显示、10kg→11kg 二次确认、5% 趋势高亮、kg⇄斤仅展示换算
- [ ] 提醒中心：待处理/已启用/已完成/已过期分组；完成幂等（家人已处理显示最新结果 U57）
- [ ] 摘要：仅所有者生成、静态快照说明、缺项/取消可见、分享不产生实时私有链接（#35）

## L3 首页面板

- [ ] 有待办：提醒条置顶且先于宠物区；无待办不制造紧急感（#7）
- [ ] 未登录：登录引导置顶、宠物/记录隐藏、资讯用品探索游客可读
- [ ] 移动首页三卡齐 + 用品并入首页（无第 5 Tab）
- [ ] 官网首页：hero 双 CTA、四板块、产品矩阵、页脚合规链接

## L4 资讯与创作

- [ ] 7 频道切换；疾病健康/营养文末免责声明；快讯"不涉时政"边界提示
- [ ] 投稿：草稿 30s 自动存、提交四步时间线、3 次驳回显示暂停 7 天不计违规（U76）
- [ ] 评论机审可见性：SUSPECT 仅自见、REJECT 双不可见（U16）
- [ ] 搜索：命中高亮、空结果兜底推荐（U17）
- [ ] 状态操作回跳原任务（resume）

## L5 探索活动

- [ ] 类型+半径筛选（非法半径回落 5km）、距离米/公里标签
- [ ] 详情导航点击计数（L5 转化）；待审评价仅作者可见
- [ ] 评价：1–5 分、1 天 1 条、全 5 短文预告人工复审、恢复重算均值（U81）
- [ ] 活动：报名前弹告知同意卡；8 拒因中文文案（U68/U69）；取消前后果说明（X10）
- [ ] 领养：**无报名/无交易按钮**、风险提示、售卖举报通道（U90）

## L6 用品导购

- [ ] 兽药/处方三通道（单条/CSV/标签）均被拦截（U77），CSV 逐行计拒因
- [ ] 普通下架：历史内容保留+已下架标；治理清除：去敏感、不可原样再上（U88）
- [ ] 价格免责与来源标注展示；方案 A 无交易（无购买按钮/无排名竞价）
- [ ] 编辑部测试徽标仅编辑+员工可见（U77）

## L7 家庭共享

- [ ] 邀请码 7 天有效；一人同时限一个家庭
- [ ] 加入页范围声明三条（自有宠物仍私有/默认只读/私有互动不开放）
- [ ] 逐动作权限：只读无编辑与摘要入口；摘要仅所有者；档位仅所有者（U61/#31/#35）
- [ ] 无权限深链先出拒绝页、不渲染私有数据
- [ ] 转移：影响清单+24h+可撤销+失败不变更（U62）；管理员转交独立、退出即失效
- [ ] 回收站：剩余天数、仅所有者恢复、恢复引导不自动执行（U66）

## L8 管理链

- [ ] 侧栏按权限过滤（无 rbac/audit 权限不显示）
- [ ] 工作台：SLA 24/48 着色、处理中锁、驳回必填模板、批量同类型无锁、快捷键 A/R/Enter/Esc
- [ ] 封禁 L1–L4 + 不能封自己 + 高危二次确认 + 审计高危标记
- [ ] 申诉 48h 内结论；成立撤销并剔除计数（U76）；家庭纠纷不代替所有者转移
- [ ] 角色保存 32 白名单+内置不可改；审计区间 ≤90 天+读出脱敏
- [ ] 运行异常待办：逾期升级显示失败原因，不出现"已运行"占位
- [ ] 认证 5 态流转；名单导出双条件+留痕+有效期（U72/U86）

## L9 合规与闭环

- [ ] 分享页四态（发布/草稿/驳回/下架/删除）文案齐、卡片与文章卡同构+来源标注（U92/U94）、登录回跳白名单
- [ ] 注销：两维依赖+活动报名四入口、冷静期 15 天、**登录≠撤销，点击确认才撤销**（#53）
- [ ] 离线：未同步≠已完成、冲突双选永不自动覆盖、登出前同步/清除双选（#32）
- [ ] 封禁页仅四动作、不转普通个人中心、处罚独立计时恢复（X15/#56）
- [ ] 规则五页可读（占位文本标注）、举报/版权通道可达、48h 反馈口径
- [ ] 官网下载页四端信息一致、非商店渠道声明、手机快捷入口
- [ ] reduced-motion 降级生效、焦点环可见、44px 点按（移动端抽查）
