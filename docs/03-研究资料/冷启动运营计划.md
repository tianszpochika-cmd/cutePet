# 冷启动运营计划（草案）

> 状态：草稿（数值为 Agent 建议值，**需负责人确认**） · 版本：v0.1 · 更新日期：2026-09-22
>
> 来源：上线合规审查 H1/H2——探索全量 + 资讯双轨进一期，缺少首发供给与审核编制计划，上线即「空城」或「违规积压」。

## 1. 首发内容供给（上线日 → 第 30 天）

| 域 | 目标（建议值） | 说明 |
|----|----------------|------|
| POI | 首发 **1–3 个城市**，每城 **≥200** 个宠物友好场所 | 运营录入 + 大众点评/地图公开信息人工整理；覆盖 7 类场所 |
| 资讯 PGC | **≥50 篇**首发文章，每频道 ≥5 篇 | 撰写排期表：上线前 2 周备齐 30 篇 |
| 清单/评测 | **≥30 篇**评测 + **≥10 条**运营清单 | 商品库 ≥300 SKU 同步录入 |
| 种子作者 | 招募 **≥20 名**养宠 KOC | 与投稿激励（曝光/作者主页）绑定，首月投稿 ≥40 篇 |
| 路线 | 首发城市 **≥10 条**路线 | 运营自制 + 种子用户征集 |
| 活动 | 上线首月 **≥6 场**本地活动 | 对接本地宠物店/机构（认证机构入驻流程） |

## 2. 审核编制测算（对应 24h SLA）

| 阶段 | 预估日均审核量 | 建议编制 |
|------|----------------|----------|
| 首月（投稿<50 + 评价/路线/评论） | ≈80–120 条 | **1 名专职审核** + 运营兼审，两班覆盖 9:00–22:00 |
| 第 2–3 月（投稿翻倍） | ≈200 条 | 2 名专职审核 |
| 机审上线后 | 机器过滤 60–80%，仅疑似转人工 | 1 名专职 + 抽审机制 |

- 前提：**机审（文字+图片）必须在上线前就绪**，纯人审无法满足 SLA。
- 积压 >50 条或队列时长 >24h → 看板告警 + 启动兼审预案。

## 3. 上线前里程碑检查（合规 + 供给）

- [ ] ICP 备案完成、备案号页脚就位
- [ ] 等保二级备案启动
- [ ] 法务四件套文案：用户协议 / 隐私政策 / 社区规范 / 儿童个人信息处理规则
- [ ] 机审（文字+图片）与举报/版权通道联调完成
- [ ] 首发供给达标（§1 表）
- [ ] 审核团队到岗并演练审核工作台
- [ ] 内部测试期（封闭/软启动）≥2 周，观察举报与积压

## 4. 与需求文档的关系

- 本文为运营输入，不改变功能范围；数据回填至 PRD 风险表与管理端 §4 编制假设。
- 软启动建议：先 Web + 移动端灰度单城市，验证 L1/L2 链后再放量（负责人决策项）。
