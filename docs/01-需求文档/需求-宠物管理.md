# 需求文档 · 宠物管理

> 状态：评审中（闭环修订完成） · 版本：v1.1 · 更新日期：2026-09-22

## 1. 模块概述

帮助宠物主人建立并持续维护宠物的数字化档案，管理健康与日常。本模块是平台的**留存锚点**，与提醒（召回）、家庭共享、资讯推荐联动。

## 2. 用户故事与功能

### B1 宠物档案（P0 · 第一期）
- 作为用户，我可以创建/编辑/归档宠物档案：昵称、物种（犬/猫/异宠）、品种、性别、是否绝育、生日/年龄、照片、体重基线。
- 我可以管理多只宠物（列表 + 切换）。
- 未登录用户可浏览资讯与商品，但创建档案需登录。

### B2 成长时间线（P0 · 第一期）
- 档案内的动态流：体重变化、健康记录、提醒完成、里程碑（生日、到家纪念日）。
- 支持按类型筛选时间线条目。

### B3 体重记录 + 曲线（P0 · 第一期）
- 快速录入体重（数值 + 时间），生成体重曲线与趋势（增/减/平稳）。
- 支持单位切换（kg / 斤）；波动规则（已决议）：单次记录较上一条变化 **≥10%** 弹二次确认，曲线较 7 日前变化 **≥5%** 高亮。

### B4 健康记录（P0 · 第一期）
- 六类记录：**疫苗接种、驱虫（体内/体外）、体检、就医、用药、过敏史**。
- 每条记录含：日期、机构/医生（可选）、备注、附件照片（可选）。
- 疫苗/驱虫记录填写未来日期后可关联或新建B5计划；无匹配计划默认单次，重复周期须用户确认，避免重复创建。

### B5 周期提醒中心 ⭐（P0 · 第一期）
- 预设提醒类型：疫苗、驱虫、喂药、体检、复诊；支持自定义。
- 周期设置：单次 / 每 N 天 / 每年同月日。
- 计划：草稿/启用/暂停/结束；待办：未到期/待处理/逾期/已完成/已跳过/已取消。排期、健康记录关联和多人处理按BR-02。
- 触达：站内消息 + 移动端推送（推送为移动端第一版核心能力）。
- **家庭共享联动**：提醒归属宠物，当前有效共享成员按本人通知偏好收到提醒（见账号需求 A5）。

### B6 健康摘要导出/分享（P0 · 第一期）
- 一键生成宠物健康摘要（档案 + 有效过敏 + 当前用药 + 近期健康记录 + 提醒计划；仅所有者核验后导出），可保存图片或分享。
- 场景：就医时给医生看、寄养时给机构看。

### B7 日常记录扩展（第二期）
- 饮食、喂食量、如厕、洗护、驱虫电商购买记录等可扩展记录项。

## 3. 业务规则

- 档案数据归属：创建者所有；**被加入家庭共享后，家庭成员按权限可查看/编辑**（权限细则见账号需求）。
- 归档（非删除）宠物：历史记录保留，不出现在默认列表。
- 删除档案：二次确认 → **软删 30 天**可恢复，期满关联数据物理删除；治理强制清除即时生效（已决议）。
- 体重曲线数据点 = 每条 B3 记录的时间戳 + 数值。

## 4. 边界与异常

- 未登录创建档案 → 引导注册/登录（L1 激活链）。
- 触达失败保留站内待办；补推重新检查任务、权限、偏好与发送期限，已完成或取消不补推。
- 宠物档案数量上限：暂不设限（运营风险低）。

## 5. 多端差异

- 移动端：第一版**全量支持**，且「快速记录体重/健康」「接收提醒推送」为移动端核心场景。
- Web：适合批量录入、查看大屏曲线、健康摘要打印。
- 管理端不涉及本模块业务数据（除举报处理外）。

## 6. 关联功能链

L1 新手激活链、L2 日常留存链 ⭐、L9 家庭共享链。
