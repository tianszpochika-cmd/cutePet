# 需求文档 · 宠物探索

> 状态：评审中（闭环修订完成） · 版本：v1.2 · 更新日期：2026-09-22

## 1. 模块概述

发现身边的宠物友好场所与活动：宠物店、宠物医院、宠物公园、遛宠路线、本地活动。第一期即交付**全部七项功能**，数据通过「运营录入 + UGC 评价纠错」自维护。

## 2. 功能需求

### D1 地图 + 列表双视图（第一期）
- 以定位为中心展示附近宠物友好场所；地图与列表可切换，联动选中。
- 无定位权限 → 降级为城市选择 + 城市级列表。
- 城市切换：手动选择城市。

### D2 筛选（第一期）
- 类型：宠物店、宠物医院、宠物公园/草坪、宠物友好餐厅咖啡、寄养、美容、训练。
- 条件：距离、评分、营业中、宠物友好属性（可带宠入内、有围栏、有水碗等）。

### D3 场所详情（第一期）
- 名称、类型、位置、营业时间、电话、设施标签、照片、评分、用户评价列表。
- 信息纠错入口（联动 D5）。

### D4 收藏 + 一键导航（第一期）
- 收藏场所到个人中心；一键唤起地图导航（调起系统地图或内置路线页，技术实现留待选型阶段）。

### D5 评价 / 图片 / 信息纠错（第一期 · UGC）
- 对到访场所打分（维度：宠物友好度、环境、服务）+ 文字 + 图片。
- 纠错：用户提交信息修正建议 → 运营处理（管理端）→ 信息更新。
- 防刷（已决议）：同账号同场所 1 天限 1 条；同设备 1 天 ≤5 条；图片重复检测；全 5 分且正文 <10 字 → 进复审队列。
- **举报（新增·合规）**：评价与场所详情提供举报入口，进入统一举报处理流。

### D6 遛宠路线（第一期，已确认）
- 浏览：按城市/距离查看他人发布的遛宠路线（起终点、途经、距离、耗时、难度、照片）。
- 发布：用户可发布路线（草稿 → 审核 → 发布，复用 UGC 审核流）。
- 收藏路线、给路线点赞。

### D7 本地宠物活动 / 领养信息（第一期，已确认）
- 活动：集市、领养日、训练课程等本地活动的发布（机构/运营）与浏览；**报名 = 站内表单**（姓名+电话，通过截止、名额、重复与同意校验后成功并通知发布方，无需人工报名审核）——已决议。
- **报名告知同意（新增·合规）**：提交前显著告知「姓名与电话将提供给活动发布方、仅用于活动通知」并取得单独同意；发布方可见报名信息，保存期限按提交后90天与活动结束/取消后30天取较早者，清理并通知发布方删除副本，留处理记录。
- 领养信息：仅信息展示与联系，**不做站内领养交易撮合**。
- **领养约束（新增·合规）**：仅限**无偿领养**，严禁变相买卖；发布方限认证机构/实名个人并经审核；页面固定风险提示（核验动物检疫证明、防诈骗、建议签订领养协议）；发现售卖信息立即下架并处置账号。
- 发布权限（已决议）：普通活动运营/认证机构经安全检查直发，普通用户先审后发；领养所有发布者均须人工审核。

## 3. 业务规则

- POI 数据来源：运营录入 + 用户纠错，第一版**不依赖第三方商业数据采购**（如需引入属技术/商务选型，阶段二讨论）。
- **地图合规（新增）**：底图与地理编码必须来自**持证地图服务商**（阶段二选型落地）；平台不自行采集道路测绘数据；遛宠路线为用户自绘示意线，不构成测绘成果。
- 评分聚合（已决议）：展示全量有效评价均值 + 评价数；被隐藏/举报成立的不计；注册未满7×24小时账号的评价仅本人待审，通过后公开并计分。
- UGC（评价/路线）全部先审后发或先发后审的策略：**普通评价过滤后公开，新号或风险命中先审后公开；路线先审后发**。

## 4. 边界与异常

- 数据稀疏地区：展示「成为第一个贡献者」引导 + 运营提报入口。
- 场所已停业：运营标记状态，列表降权/隐藏。
- 定位失败：城市兜底（同 D1）。

## 5. 多端差异

- 移动端第一版全量，且是**探索主场景**（外出时使用）：地图、导航、现场评价。
- Web：城市级浏览、大屏地图、路线查看。

## 6. 关联功能链

L5 探索到店链、L4 UGC 生产链（评价/路线）、L8 运营治理链、L7 分享拉新链。
