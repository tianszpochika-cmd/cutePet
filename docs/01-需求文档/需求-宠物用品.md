# 需求文档 · 宠物用品（方案 A · 内容导购）

> 状态：已定稿（范围已确认：方案 A，不做交易） · 优先级：P1 · 期次：第一期 · 版本：v1.0

## 1. 模块概述

宠物用品的**内容型导购**：以商品库 + 评测清单创造选购价值，帮用户做对决策。**不引入购物车、订单、支付、物流、售后、商家入驻。**

## 2. 功能需求（第一期）

### E1 商品库与分类浏览
- 分类：主粮、零食、玩具、清洁护理、医疗保健、出行用品、服饰窝垫。
- 商品信息：名称、分类、规格/口味、参考价格区间、品牌、封面、要点标签（如「适合幼犬」「无谷」）。
- 浏览：分类列表 + 搜索 + 筛选（分类/适用宠物/价格区间）。
- ⚠️ 参考价格与购买引导：第一版为内容性信息，跳转外链与否见「业务规则」。

### E2 评测 / 清单内容（导购价值核心）
- 评测文章：绑定商品的深度评测（复用资讯的内容体系，商品卡与文章双向关联）。
- 清单：运营/作者维护的「好物清单」（如「幼猫第一份粮怎么选 TOP10」），清单内含商品卡。
- 商品详情页展示：要点、相关评测、所在清单；**一期不做多商品参数对比工具**（对比列入二期，已决议）。

### E3 收藏与好物清单
- 收藏商品到「我的清单」；对清单点赞收藏。

### 第二期
- E4 按宠物档案的适配推荐（按体型/年龄/品种选品）。

## 3. 业务规则

- 商品库维护方：运营录入（第一版**无商家入驻**）。
- 数据性质：参考信息为主，**不承诺价格准确性**；**一期不提供购买外链跳转**（纯内容导购，已决议；二期评估外链及合规文案）。
- 评测内容必须标注是否为编辑部测试/资料整理（可信度治理）。
- 商品下架/信息过期：保留历史评测中的展示，但商品库隐藏并提示「已下架」。

## 4. 边界与异常

- 搜索无结果 → 引导到相关分类或评测内容。
- 评测绑定的商品被删除 → 文章内商品卡降级为纯文本。

## 5. 明确不做（第一版）

❌ 购物车、订单、支付、物流、售后、退款、商家入驻与商家后台、比价爬虫。

## 6. 多端差异

- 移动端第一版全量（浏览、评测阅读、收藏）。
- Web：适合大屏参数对比与清单阅读。

## 7. 关联功能链
