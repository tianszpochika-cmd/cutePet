# PRD · 总纲

> 状态：评审中（闭环修订完成） · 版本：v1.2 · 更新日期：2026-09-22

## 1. 项目背景

产品假设：有固定照护安排的养宠人与共同照护家庭，需要准确记录、避免重复处理并明确下次安排；在需要时获取资讯、附近资源及选购参考。目标用户与验证方法见项目愿景及用户调研计划，尚未取得真实调研结论。

## 2. 产品定位

一站式宠物生活服务平台，覆盖「管理 · 资讯 · 探索 · 用品」四大场景，支持用户端 Web、官网、管理端、移动端四端。

## 6. 非功能性要求与外部验证

- 性能（已决议）：核心页首屏 ≤3s（4G）、常用接口 P95 ≤1s、可用性 ≥99.5%
- 兼容（已决议）：Web 覆盖 Chrome/Edge/Safari/Firefox 近 2 大版本；移动覆盖 Android 10+ / iOS 15+ 主流机型
- 安全：账号安全、内容安全（UGC 审核前置）
- 数据合规与隐私：注销、数据导出、隐私开关为一期必备；隐私政策/用户协议/UGC 授权条款**文案由法务出具（外部依赖）**；隐私合规功能清单见 `需求-账号与用户体系.md` §5
- **合规资质（既有上线检查清单，适用性与完成证据须由专业人员按实际发布形态核定）**：
  ① 官网与用户端 Web 完成 **ICP 备案**，页脚展示备案号并链接工信部查询页；
  ② 移动端形态确定后完成**工信部 App/小程序备案**（2023 年起强制，阶段二落地、需求前置）；
  ③ **公安联网备案**；
  ④ **网络安全等级保护二级**测评与备案；
  ⑤ 一期无商业化，暂不申请 ICP 经营许可证/EDI（商业化启动时重新评估）。
- **未成年人（已决议 · 方案甲）**：注册按年龄分支——年满 14 周岁自主注册；不满 14 周岁走**监护人同意流程**（监护人手机号验证 + 儿童个人信息专门处理规则）。**青少年模式一期不实现**（负责人决策，接受应用商店审核与监管抽查风险；复评节点：上线前、移动端下载量过万前）。

## 7. 版本规划

- **第一版（MVP）范围**：见 需求全景-功能清单.md 第 5 节 In Scope
- **第二版候选**：积分签到、个性化推荐、适配推荐、裂变增长、召回策略、商业化
- 长期方向：验证留存与内容飞轮后，评估商家/交易能力与商业化（明确在第一版之外）

## 8. 风险与依赖

| 风险 | 影响 | 应对 |
|------|------|------|
| UGC 进 MVP 带来审核治理成本 | 管理端工作量、内容风险 | 审核流程进第一版；先审后发 |
| 探索全量（路线/活动/POI） | 数据供给压力 | 评价纠错 + 运营录入冷启动 |
| 家庭共享增加数据模型复杂度 | 档案权限、提醒归属 | BR-03/04已明确对象权限、转移及退出，开发按对应场景验收 |
| 四端全量同步交付 | 交付节奏 | 交互/视觉阶段先定跨端复用策略 |
| 备案与等保有周期（数周） | 上线节奏 | 立即启动 ICP 备案，与开发并行 |
| 审核人力不足 → 违规积压 | 冻结 24h SLA、内容安全 | 按《冷启动运营计划》测算编制，积压监控进看板 |
| 无青少年模式（方案决策） | 商店审核/监管抽查 | 注册年龄分支做实；复评节点见 §6 |
| 无商业化 → 纯净支出 | 预算 | 负责人确认一期预算模型（备案/人力/内容/服务器） |
