# 需求文档 · 宠物资讯

> 状态：已定稿（上线合规修订 v1.1） · 优先级：P0 · 期次：第一期（含 UGC） · 版本：v1.1

## 1. 模块概述

提供科学、可信的养宠知识与行业动态，是平台的**停留引擎**；UGC 投稿已确认进入 MVP，保障内容供给的可持续运营。

## 2. 功能需求

### 内容消费（P0 · 第一期）

**C1 首页 feed + 分类频道**
- 首页：推荐流（编辑精选起量，个性化推荐二期）。
- 频道分类：犬、猫、异宠、营养、疾病与健康、训练与行为、行业快讯。
- 信息流形态：图文卡片；支持置顶、专题卡。
- **免责声明（新增·合规）**：疾病与健康频道及涉医内容页固定展示「内容仅供科普参考，不构成兽医诊疗建议，用药与诊疗请遵医嘱」。
- **快讯边界（新增·合规）**：行业快讯仅限宠物行业动态，**严禁时政/社会新闻**（互联网新闻信息服务需许可，明确越界）。

**C2 搜索**
- 搜文章标题/摘要/标签/作者；结果按相关度排序；空结果兜底推荐。

**C3 内容互动**
- 点赞、收藏、评论（一级评论 + 回复）、分享（生成分享卡片）。
- 评论能力对已登录用户开放；评论需过安全过滤（治理见管理端）。
- **举报（新增·合规）**：文章与评论提供举报入口（类型 + 说明），进入统一举报处理流（见《需求-平台规则与客服》）。

**C4 收藏夹管理**
- 收藏内容的列表、分类整理（自定义分组）、取消收藏。

**C5 关注作者/话题**
- 关注后可在「关注」入口看到作者动态与话题内容。

**C6 专题/榜单/快讯**
- 运营可创建专题（聚合文章）、榜单（如月度热门）、快讯（短讯流）。
- **文案合规（新增）**：榜单「TOP/N」须有可核查的排序依据；禁用广告法极限词（最/第一/国家级等）；未来付费合作内容须显著标注「广告」。
- **举报入口**：同 C3（新增）。

### UGC 生产（C7/C9 · P0 · 第一期，已确认进 MVP）

**C7 创作中心**
- 入口：个人中心 → 创作中心。
- 能力：撰写（标题/正文/封面/分类/标签）、**草稿箱**、提交审核、查看审核状态。
- 投稿状态机：`草稿 → 待审核 → 审核中 → 已发布 / 已驳回（附意见，可修改重提）→ 已下架`。
- 作者等级与发布权限的挂钩（如先审后发 vs 信用免审）：第一版**统一先审后发**，信用体系二期。

**C9 作者主页与创作数据**
- 作者主页：简介、文章列表、粉丝/关注。
- 创作数据：浏览、点赞、评论、收藏（仅作者可见自己的）。

### 第二期

- C8 个性化推荐（按宠物品种/标签匹配内容）。

## 3. 业务规则

- 内容来源：PGC（运营编辑）+ UGC（用户投稿），**双轨并行**。
- 发布权限：登录用户默认可投稿；违规封禁用户取消投稿资格。
- 评论/投稿均需内容安全过滤；命中疑似违规进入人工复审。
- UGC 内容版权（产品侧已决议）：投稿即视为授权平台展示与推广；授权条款文案由法务定稿（外部依赖）。

## 4. 边界与异常

- 内容不可用（下架/删除）→ 详情页降级提示 + 相关推荐。
- 审核超时 → 作者可查看排队状态；超时提醒运营（管理端指标）。
- 未登录互动（点赞/评论/收藏）→ 引导登录，登录后回跳原内容。

## 5. 多端差异

- 移动端第一版全量：消费 + 投稿 + 互动均可完成（写作体验可提供简化编辑器）。
- Web：适合长文阅读与创作中心写作。
- 官网：仅精选内容展示（引流入口，具体见多端矩阵）。

## 6. 关联功能链

L3 内容消费链、L4 UGC 生产链、L8 运营治理链、L7 分享拉新链。
