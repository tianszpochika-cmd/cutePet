# 需求文档 · 账号与用户体系（含家庭共享）

> 状态：已定稿（上线合规修订 v1.1） · 优先级：P0 · 期次：第一期（家庭共享已确认要做） · 版本：v1.1

## 1. 概述

统一的账号体系，支撑四大模块与多端登录状态；家庭共享为第一版确定需求，影响宠物档案的权限模型。

## 2. 用户角色

| 角色 | 说明 | 关键权限 |
|------|------|----------|
| 游客 | 未登录 | 浏览资讯/商品/探索（只读），互动与建档需登录 |
| 普通用户 | 注册养宠人 | 档案、记录、提醒、投稿、评价、收藏 |
| 家庭创建者 | 创建家庭组 | 管理成员、共享自家宠物档案 |
| 家庭成员 | 被邀请加入 | 按权限查看/编辑共享宠物档案、接收共享提醒 |
| 内容创作者 | 普通用户的投稿身份 | 投稿、创作中心、作者主页 |
| 运营人员 | 平台编辑/审核/POI 运营 | 审核、内容与数据运营（管理端） |
| 管理员 | 超级权限 | 权限分配、封禁、审计 |

> 运营/管理员仅存在于管理端，与 C 端账号体系隔离管理（细则设计阶段细化）。

## 3. 功能需求（第一期）

### A1 注册登录
- 手机号验证码注册登录 + **微信登录**（一期第三方渠道定为微信，已决议；其他渠道二期）。
- 多端登录态互通：Web、移动端共享同一账号与数据。
- **协议勾选（新增·合规）**：首次注册/启动须勾选同意《用户协议》《隐私政策》（默认不勾选，可点击查看全文）。
- **年龄分支（方案甲 · 已决议）**：注册时询问年龄——≥14 岁自主注册；**<14 岁进入监护人同意流程**（监护人手机号验证确认 + 展示《儿童个人信息处理规则》，监护人可随时撤销同意）。
- **实名制（新增·合规）**：贯彻「后台实名、前台自愿」——手机号注册满足后台实名（SIM 实名制），前台昵称头像自愿使用，账号信息须过审核（见管理端内容安全）。
- **账号找回/换绑（新增）**：已登录状态换绑手机号（原号验证或人工申诉）；注销冷静期内可登录撤销。

### A2 个人资料 + 养宠标签
- 昵称、头像、养宠标签（养的物种/品种、只数、养宠阶段：新手/资深）。
- 标签用于二期个性化推荐的依据。

### A3 多宠家庭档案
- 一个账号管理多只宠物（见宠物管理 B1）。

### A4 隐私设置 / 注销 / 数据导出（合规刚需）
- 隐私设置：档案可见性（默认仅自己与家庭成员）、互动可见性。
- 注销：冷静期 **15 天**（已决议）内可撤销；期满数据按合规策略删除或匿名化（UGC 默认匿名化保留）。
- 数据导出：支持导出个人资料与宠物档案数据。

### A5 家庭共享 ⭐（已确认进第一版）
- **模型**：一个「家庭组」= 1 个创建者 + N 个成员；宠物档案可加入某个家庭组实现共享。
- **邀请**：创建者生成邀请链接/邀请码，受邀人注册/登录后加入。
- **权限（第一版两档）**：
  - 共享可管理：查看 + 编辑档案、录入健康记录、处理提醒；
  - 共享只读：仅查看（可后续迭代为更细粒度）。
- **规则**：
  - 宠物可被多个账号共享，但**所有权唯一**（创建者）；
  - 创建者可移除成员；成员可退出家庭；
  - 提醒与时间线对家庭成员同步（联动 B2/B5）；
  - 家庭组数量上限：暂不设限；**同一用户同时仅可属于一个家庭**（加入新家庭前须退出原家庭）——已决议。
- **边界**：被移除的成员立即失去共享档案访问权；其个人收藏等私有数据不受影响。

### A7 帮助、客服与申诉（新增·合规）
- 端内入口：设置 → 帮助与客服（FAQ、联系表单/邮箱）。
- 封禁/处置通知必须附**申诉入口**；申诉经管理端处理，结果经消息中心反馈（时限 ≤48h）。

### 其他
- A6 签到/积分成长 → 第二期。
- 家庭共享链 = L9（见功能清单）。

## 4. 业务规则

- 一个手机号/第三方身份 = 一个账号。
- 封禁账号：不能登录或登录受限（由管理端执行），已有数据保留待处理。
- 未成年人（**方案甲 · 已决议**）：注册年龄分支，<14 岁走监护人同意流程 + 儿童个人信息专门处理规则；**青少年模式一期不实现**（负责人决策，风险已记入 PRD §8，复评节点：上线前/移动端下载量过万前）。

## 5. 隐私合规需求清单（上线合规修订新增）

| # | 需求 | 说明 |
|---|------|------|
| 1 | 收集清单公示 | 隐私政策附「个人信息收集清单」：类型、目的、范围（账号、档案、日志、相机/定位用途） |
| 2 | SDK 清单公示 | 预留「第三方 SDK 清单」能力（登录/推送/地图），随阶段二选型填充 |
| 3 | 勾选同意 | 注册/首次启动勾选《用户协议》《隐私政策》，默认不勾选；设置内可查阅全文与撤回同意 |
| 4 | 权限说明 | 定位/相机/通知申请时给出用途说明；拒绝非核心权限不拒绝核心服务 |
| 5 | 导出身份核验 | 数据导出前验证码核验身份；导出行为留痕 |
| 6 | 埋点采集告知 | 数据埋点列入收集清单与隐私政策 |
| 7 | 第三方提供告知 | 向第三方提供个人信息的场景（如活动报名），提交前显著告知并**单独同意**（见探索需求） |
| 8 | 家庭共享告知 | 发出共享邀请前提示「档案信息将对家庭成员可见」 |
| 9 | 法务文案（外部依赖） | 用户协议/隐私政策/社区规范/儿童个人信息规则全文由法务出具 |

- 个人信息收集最小化、注销与数据导出为一期必备（已具备）。

## 6. 多端差异

- 移动端第一版全量（登录、资料、家庭共享管理均可完成）。
- 邀请链接需兼容多端打开（在 Web 打开邀请 → 引导移动端，或反之）。
