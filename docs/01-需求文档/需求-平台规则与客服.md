# 需求文档 · 平台规则与客服（上线合规新增）

> 状态：评审中（闭环修订完成） · 版本：v1.1 · 更新日期：2026-09-22
>
> 来源：`04-规范与模板/上线合规审查报告.md` B2/B8。对应平台规则三件套：用户协议、隐私政策、社区规范。

## 1. 平台规则展示与触达

- **规则页**（全局可查）：用户协议、隐私政策、社区规范（内容发布规范）、儿童个人信息处理规则（方案甲）。
- 入口：我的 → 关于/规则页；官网页脚；注册勾选处链接。
- **规则更新**：重大变更须弹窗/公告通知用户并重新取得同意（涉及权利义务时）。
- 违规处置依据公示：社区规范中明确违禁内容分类与处置阶梯（L1–L4，见管理端需求 §2.8）。

## 2. 举报（C 端 → 管理端闭环）

- **举报入口**（新增需求）：文章、评论、评价、场所、路线、活动、用户主页 → 「更多/…」→ 举报。
- 表单：举报类型（色情低俗/政治敏感/广告引流/诈骗/侵权/虚假信息/其他）+ 说明 + 可选截图。
- 流程：提交 → 统一举报队列（管理端 §2.9）→ **普通举报 ≤48h 处理** → 结果通知举报人。
- 举报不成立不等于恶意；仅人工确认滥用后方可限频，并说明理由、期限与申诉入口。

## 3. 版权「通知-删除」通道（避风港）

- **公示专用通道**：官网页脚 + 端内帮助页提供版权投诉邮箱/表单（权利证明 + 涉嫌侵权链接 + 联系方式）。
- 处理：收到合格通知 → **立即下架**涉嫌内容 → 通知发布者 → 发布者可**反通知**申诉（附不侵权证明）→ 恢复或维持下架；全过程留痕。
- 时限：下架即时执行；反通知处理 ≤7 天。

## 4. 客服与申诉

- **入口**：我的 → 帮助与客服（FAQ / 联系表单或邮箱）；封禁/处置通知内附**申诉入口**。
- 申诉流程：提交申诉（单号可查）→ 管理端申诉队列（权限点 appeal.handle）→ 结果经消息中心反馈，**≤48h**。
- 客服与运营的分界：产品问题 → 客服；内容处置 → 申诉通道。

## 5. 违规处置公示与告知

- 处置发生时向用户推送通知：处置类型、依据（社区规范条款）、期限、申诉途径。
- 解除处置同样通知；处置记录用户侧可查（我的 → 消息中心）。

## 6. 多端差异

- Web/移动均需具备举报与帮助入口；官网承担公示职责（备案号、规则页、投诉举报与版权通道）。
- 管理端：举报队列、版权工单、申诉队列见 `功能设计-管理端.md`。
