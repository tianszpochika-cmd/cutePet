> 状态：已定稿（范围决策已确认） · 版本：v1.0 · 更新日期：2026-09-22

## 1. 范围决策（已确认）

| # | 决策点 | 结论 |
|---|--------|------|
| 1 | 宠物用品 | **方案 A：内容导购**，不引入购物车/订单/支付/商家入驻 |
| 2 | UGC 投稿 | **进入 MVP**（含审核治理） |
| 3 | 商业化 | **不进入第一版**（无广告、无佣金、无会员） |
| 4 | 家庭共享 | **要做，进入第一版** |

## 2. 核心思路：增长运营飞轮

```
建档留存 → 提醒召回 → 资讯停留 → 探索场景 → UGC与分享 → 拉新回流
```

- **管理 = 留存锚点**（提醒是唯一的主动打扰权）
- **资讯 = 停留引擎**（UGC 保证供给可持续）
- **探索 = 线下场景**（评价纠错实现数据自维护）
- **用品 = 导购价值**（不交易，靠内容与推荐创造价值）

## 4. 功能链（端到端）

| 链路 | 路径 | 目标指标 |
|------|------|----------|
| L1 新手激活链 | 落地 → 注册(A1) → 建档(B1) → 设提醒(B5) → 进首页 | 首日建档完成率 |
| L2 日常留存链 ⭐ | 提醒推送(H2) → 记录(B3/B4) → 看曲线(B2) → 刷资讯(C1) | 周活/记录频次 |
| L3 内容消费链 | 通知/首页 → feed(C1) → 详情(C3) → 收藏/评论 → 关注(C5) → 回访 | 停留时长/回访率 |
| L4 UGC 生产链 | 消费 → 投稿(C7) → 审核(F) → 发布 → 获互动 → 创作数据(C9) | 供给量/审核通过率 |
| L5 探索到店链 | 定位 → 筛选(D2) → 详情(D3) → 导航(D4) → 到店 → 评价(D5)回流 | 收藏/导航转化 |
| L6 用品导购链 | 档案/资讯 → 商品列表(E1) → 评测清单(E2) → 收藏(E3) → 第二期推荐(E4) | 导购点击/收藏率 |
| L7 分享拉新链 | 时间线/资讯/路线 → 分享 → 落地页 → 回到 L1 | 裂变系数 |
| L8 运营治理链 | UGC → 审核(F) → 发布 → 看板 → 推荐位加权 → 刺激生产 | 内容飞轮转速 |
| L9 家庭共享链 | 创建家庭(A5) → 邀请成员 → 共管档案(B1) → 双方收到提醒(H2) | 共享激活率 |
| L10 召回链 | 休眠用户(H4) → 周期提醒/内容推送 → 回访 → 回到 L2 | 召回率（H4 二期） |

## 5. 范围边界

**第一版 In Scope**：A1-A5、B1-B6、C1-C7+C9、D1-D7、E1-E3、F 全部、H1-H2、L1-L9。

**第一版 Out of Scope**：商业化(G 全部)、交易(E4 交易系列)、A6/C8/E4(适配推荐)/H3/H4、宠物医疗问诊、宠物社交聊天、领养交易撮合。

**明确不做**：购物车、订单、支付、物流、售后、商家入驻。
