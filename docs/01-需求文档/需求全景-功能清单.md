## 2. 核心思路：照护协作与场景服务

```
建档 → 提醒待办 → 记录照护 → 家人同步 → 下次安排
按需要进入：资讯知识 / 附近探索 / 内容导购 / 创作分享
```

- **管理 = 留存锚点**（照护、安全、活动变更等通知分类授权）
- **资讯 = 停留引擎**（UGC与运营供给的持续性须真实验证）
- **探索 = 线下场景**（评价纠错与运营核验共同维护）
- **用品 = 导购价值**（不交易，靠内容与推荐创造价值）

## 4. 功能链（端到端）

| 链路 | 路径 | 目标指标 |
|------|------|----------|
| L1 新手激活链 | 落地 → 注册(A1) → 建档(B1) → 设提醒(B5) → 进首页 | 首日建档完成率 |
| L2 照护协作链 ⭐ | 提醒待办 → 记录照护 → 完成本次 → 家人同步 → 下次安排；资讯可选 | K03–K08 |
| L3 内容消费链 | 通知/首页 → feed(C1) → 详情(C3) → 收藏/评论 → 关注(C5) → 回访 | 停留时长/回访率 |
| L4 UGC 生产链 | 消费 → 投稿(C7) → 审核(F) → 发布 → 获互动 → 创作数据(C9) | 供给量/审核通过率 |
| L5 探索导航链 | 定位/城市 → 筛选 → 详情 → 发起导航；用户可另行评价 | K12，不推断到店 |
| L6 用品导购链 | 首页/资讯 → 商品与评测清单 → 收藏 → 主动回访 | K13–K14；E4二期 |
| L7 分享回流链 | 公开资讯/路线/清单 → 分享链接 → 公开页 → 登录回原任务；摘要仅静态图 | K15 |
| L8 运营治理链 | 投稿/修改版 → 审核 → 发布/下架 → 举报申诉 → 复核恢复 → 指标复盘 | K11/K19 |
| L9 家庭共享链 | 建家庭 → 邀请 → 所有者选择共享及档位 → 协作记录/待办 → 退出解除权限 | K16 |
| L10 召回链 | 休眠用户(H4) → 周期提醒/内容推送 → 回访 → 回到 L2 | 召回率（H4 二期） |
| L11 活动生命周期 | 发布者身份 → 发布/审核 → 报名 → 查询/名单 → 变更取消通知 → 结束清理 | K17–K18 |
| L12 账号与家庭退出 | 核验 → 转移或解除依赖 → 退出/冷静期 → 权限与数据清理 → 查询 | K19及权限场景 |
| L13 内容修订 | 线上版 → 修改稿 → 固定版本审核 → 替换/驳回 → 引用同步 | K11 |

## 5. 范围边界

**第一版 In Scope**：A1-A5、B1-B6、C1-C7+C9、D1-D7、E1-E3、F 全部、H1-H2、L1-L9及既有需求的L11-L13生命周期。

**第一版 Out of Scope**：商业化(G 全部)、交易体系、A6/C8/E4(适配推荐)/H3/H4、宠物医疗问诊、宠物社交聊天、领养交易撮合。

**明确不做**：购物车、订单、支付、物流、售后、商家入驻。
